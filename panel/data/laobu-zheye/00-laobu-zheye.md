# laobu-zheye：老布褶也以物喻人短片写法

一句话：**拿一件日常物品说人。** 对话全是关于物品的，每一句都是关于人的。

> 句句不提人，句句不离人。

本技能的方法只取 28 条完整核实的视频（见附录 A），引用台词均为转写原文或简介原文。另有 10 条因转写不完整标“未核实”，只列附录 B，不作方法例证。

## 0. 六道锁：动笔前必须问清（缺一不可默认）

写之前先把这六项对齐。用户已明确的不问；没说的，用推荐默认值并**在交付说明里写明用了默认**。绝不静默跳过。

| 锁 | 取值 | 说不清时默认 |
|---|---|---|
| 人的处境 | 关系 / 婚姻 / 长大 / 回家 / 自由 / 价值 / 习惯 / 选择 / 价格 | 关系：两个人之间的一件事 |
| 物品 | 日常、具体、已在场景里的一个东西 | 店铺柜台上现成的东西 |
| 场景 | 花店 / 饭店 / 鞋店 / 服装店 / 书店 / 饮品店 / 水果摊 / 瓜摊 / 面馆 / 蛋糕店 / 便利店 / 鸟店 / 车行 / 装修公司 | 一家店，柜台前两个人 |
| 物品的翻面 | 它的“毛病”恰恰是它的本质 | 鱼刺是鱼的骨头（§3） |
| 点睛台词 | 一句 ≤50 字的台词，关于物品，翻转全局 | 先定这句，再写前面 |
| 篇幅 / 语气 | 2–8 分钟；两个人对话，无旁白无解说；普通话，带一点生活口语 | 4–6 分钟，两人对话 |

**先写最后一句，再写第一句。** 点睛台词就是最后一句（§6）。

## 1. 核心：以物喻人

### 1.1 一句话

**物品就是人。** 对话的表面全是物品，底下全是人。

- 《假花》表面在说花，底下在说：你想要一个人永远是最好的样子，又不想付出照顾。
- 《水》表面在说一杯饮料，底下在说：你以为懂你的那个人，只是恰好在那里。
- 《鸟，笼》表面在说买鸟，底下在说：你爱他，还是你占有他。
- 《合脚》表面在说买鞋，底下在说：你想要新的，又不愿意吃磨合的苦。

### 1.2 句句不提人，句句不离人

三条纪律：

1. **人不能当主语。** 台词的主语永远是物品：“这花”“这鞋”“这杯子”“这瓜”。不说“你这个人就是这样”，说“这鞋就是这样”。
2. **道理不能讲出来。** 不说教，不总结，不点破“这个故事告诉我们”。道理只存在物品的逻辑里，点睛台词就是道理，但它说的是物品。
3. **人只在物品的缝里出现。** 人的处境只通过物品的选择、用法、价格、去留来呈现：要不要、买不买、租不租、新还是旧、留不留、放不放手。

反例：直接说“你太自私了”——这是说教，不是老布。老布说：“你都没让他飞，你怎么知道他属于你？”（《鸟，笼》）——主语是鸟，说的是人。

### 1.3 老布是谁

对话里通常两个人：一个是顾客（要东西的人），一个是店主/老布（问问题的人）。老布多半演店主——那个不断追问、不断翻面的人。也有他演顾客的时候（《喜喜车》《sha 瓜》里他是挑东西的人）。谁演谁不重要，重要的是**两个人，一问一答，物品在中间**。

## 2. 选物品：怎么挑一件能说人的东西

### 2.1 五条标准

| 标准 | 意思 | 反例 |
|---|---|---|
| 日常 | 菜市场、柜台上随手能拿到的东西 | 罕见、昂贵、需要解释的东西 |
| 具体 | 一个实物，能拿在手里，能用、能穿、能吃、能住 | 抽象概念（爱、自由、梦想本身） |
| 已在场景里 | 物品本来就在那个店里，不用凭空搬进来 | 为了寓意硬塞进来的道具 |
| 两面 | 它有“是什么”和“被人当成什么”两面 | 只有一面，没得争 |
| 能争论 | 它的用法、价格、新旧、去留能吵起来 | 没人会在乎它怎么样 |

### 2.2 物品的“毛病”就是它的本质

选物品，先找它的“毛病”——那个让人嫌弃的地方。**那个毛病，就是它要说的人话。**

| 物品 | 它的“毛病” | 毛病说的人话 |
|---|---|---|
| 鱼刺（03） | 刺太多，麻烦 | 对于你来说那是麻烦的刺，对于鱼来说那是人家的骨头 |
| 杯子（07） | 被当烟灰缸用 | 那只是你给它的定义，改变不了它的本质 |
| 水（13） | 没味道 | 水本身没有味道，是你的焦渴赋予了它味道 |
| 瓜（35） | 价格对不上 | 三块五是他，四块五是他，六块也是他 |
| 衣服（37） | 被很多人试过 | 你试了这么多才找到他，他被那么多人试过才遇到你 |
| 鸟（39） | 会飞走 | 他一定得会飞，但是他不能从我的身边飞走 |

### 2.3 一件物品只用一次

38 条视频，物品没有重复的。同一主题可以多拍，但每次换一件物品：

- 鞋/衣服/试穿主题：10《合脚》（鞋）→ 16《好！鞋》（球鞋）→ 17《附寸》（衣服）→ 37《衣前，以后》（衣服）——每次换物品、换角度。
- 车主题：20《长大》（新车）→ 23《租·购》（租车）→ 31《喜喜车》（二手车）→ 33《先 后》（同一辆车，续集）。
- 房子主题：15《心现》（厨房）→ 21《习惯》（智能房子）→ 22《条件》（图纸）。
- 回家主题：25《回家》→ 27《西门少年》→ 28《欢迎回家》→ 29《迷失归途》（系列，见 §4.7）。

**新片先查物品库：这件东西以前用过没有？用过就换一件。**

### 2.4 物品库（38 条，见附录 A）

高频场景是“店”：花店、饭店、鞋店、服装店、书店、饮品店、水果摊、瓜摊、面馆、蛋糕店、便利店、鸟店、车行、装修公司。**先定店，再定物品，物品本来就在店里。**

## 3. 嵌意思：三步翻面法

意思不是贴上去的，是从物品本身翻出来的。三步：

### 3.1 第一步：立一个偏见

先让一个人对物品下一个判断——通常是嫌弃、想要、或误解。

- “鱼刺太多，麻烦。”（03）
- “我要的是新的，还合脚的。”（10）
- “这不就是水吗？”（13）
- “四块五的话才是好瓜，所以他肯定有问题。”（35）
- “我要的是不能飞的鸟。”（39）

### 3.2 第二步：用物品本身翻过来

不讲道理，只讲物品的事实。物品的事实一摆出来，偏见就站不住了。

- 鱼刺是鱼的骨头——你要鱼好吃，又不要它的骨头。（03）
- 穿过的鞋最合脚——新的合脚和别人穿过，两个都要，就得吃磨合的苦。（10）
- 他一直都是水——你当时要的是解辣解渴，什么款式都可以。（13）
- 瓜是吃的，不是看的——你都没尝过，光是对比价格，你就怀疑他有问题。（35）
- 你都没让他飞，你怎么知道他属于你？（39）

### 3.3 第三步：问一句，收住

翻面之后不总结，问一句。问题就是点睛台词的前奏（§6）。

- “像谁的样啊？”（22《条件》）
- “洗得干净吗？”（19《牛奶杯》）
- “所以您单靠一个结局，就把整本书给否定了？”（18《一半结局》）
- “你怎么知道他属于你？”（39《鸟，笼》）

**翻面的力来自物品，不来自作者。** 如果翻面需要讲一个物品之外的道理，说明物品选错了，换一件。

## 4. 结构：七种常用结构

### 4.1 店铺对话体（最常用）

顾客进店 → 要东西 → 店主问 → 一问一答推进 → 翻面 → 点睛台词收尾。

适用：01、02、03、05、07、10、13、16、17、18、19、30、31、32、35、37、39。

```
顾客：我要 X（说出偏好）
店主：你确定吗？（问一句）
顾客：……（坚持偏好）
店主：……（讲物品的事实）
顾客：……（动摇 / 反驳）
店主：点睛台词（翻面，收尾）
```

### 4.2 试穿 / 试用体

试一件东西 → 合适 → 发现毛病 → 对照另一件 → 揭晓 → 点睛台词。

适用：10《合脚》、16《好！鞋》、17《附寸》、37《衣前，以后》。

核心句式：“穿过的鞋最合脚”（10）、“二手衣服的好处就是，不用您自个儿磨合，谁穿谁舒服”（17）、“衣服是穿以后，不是穿以前”（37）。

### 4.3 新旧对照体

新的 vs 旧的 / 新鲜的 vs 罐头的 / 预制的 vs 亲手做的——两边摆出来，让人选，选完翻面。

适用：13《水》、16《好！鞋》、17《附寸》、28《欢迎回家》（预制年 vs 亲手做）、30《草莓罐头》（新鲜草莓 vs 草莓罐头）、31《喜喜车》（新车 vs 二手车）、37《衣前，以后》。

核心句式：“而他既没有草莓这么新鲜，也没有草莓那么甜啊”（30）、“这过年不是熬日子，反倒是最不应该省事的时候”（28）。

### 4.4 租 vs 买体

租的东西 vs 买的东西——名分、付出、归属。

适用：21《习惯》（房子）、23《租·购》（车）、33《先 后》（同一辆车，续集）。

核心句式：“你只是个租客”（23）、“今儿租吗？我，不租。拥有。”（33）。23 和 33 互为一体两面：23 的结论是“你跟他在一起好，不是因为他好，是因为你好”，33 把它翻过来——“不是因为你好，是因为他本身就很好”。

### 4.5 数字体

用一个精确的数字锚住全片，数字本身会说话。

| 数字 | 出处 | 数字说什么 |
|---|---|---|
| 846 天 | 23《租·购》 | 在一起的时间 |
| 23,678.65 元 | 25《回家》 | 回家的成本 |
| 778 公里 | 25《回家》 | 回家的距离 |
| 2000 公里 | 29《迷失归途》 | 回家的路 |
| 100 辆车 | 31《喜喜车》 | 挑来挑去 |
| 三块五 / 四块五 / 六块 | 35《sha 瓜》 | 价格变，瓜没变 |
| 五块 / 十块 | 36《正 好》 | 正好 |
| 361 天 | 27《西门少年》 | 还剩的约定 |
| 37.5 度 | 22《条件》 | 图纸上的条件 |
| 12.5 公斤 | 22《条件》 | 洗烘一体 |

**数字要精确到小数点后两位、精确到个位数。** “很多天”没有力量，“第八百四十六天”有力量。

### 4.6 三联重复体

一句关键台词重复多次，越重复越重。

- “你还要吗”×14（16《好！鞋》）
- “我给你买了”×14（16《好！鞋》）
- “是你自己愿意吃爱情的苦罢了”×3（38，未核实，仅台词可辨）
- “我为什么会在里面？”×5（38，未核实，仅台词可辨）
- “三块五是他，四块五是他，六块也是他”（35，一句里三连）

**重复不是凑时长，是加重。** 每重复一次，意思往下沉一分。

### 4.7 系列体

同一主题分集拍，每集换一个角度，集与集之间互相照应。

《向北也向南》三集（吉利银河 E5 系列）：

| 集 | 标题 | 角度 | 点睛台词 |
|---|---|---|---|
| 01 | 29《迷失归途》 | 找不到回家的路 | “你自己回家的路都找不着了” |
| 02 | 28《欢迎回家》 | 预制的年 vs 亲手做的年 | “这过年不是熬日子，反倒是最不应该省事的时候” |
| 03 | 27《西门少年》 | 穿不穿棉裤，留不留得住 | “人这一辈子，不是熬日子，是数回来的次数”（情节未核实，台词逐字可辨） |

**系列的每一集都要能独立成立。** 没看过第一集的人，看第三集也要能看懂。

## 5. 对话：两个人，一问一答

### 5.1 没有旁白，没有解说

38 条里没有一条用旁白讲道理。故事全在对话里。对话就是剧情。

### 5.2 问句驱动

推进靠问句，不靠陈述。每一段对话都是一问一答：

- “您是想要新的，还是合脚的？”（10）
- “那你愿意为他花更多的钱吗？”（23）
- “图里的这些东西，真的都是您喜欢的吗？”（22）
- “你怎么知道他属于你？”（39）
- “洗得干净吗？”（19）

**写不下去的时候，加一个问句。** 问句就是下一句的钩子。

### 5.3 口语，不书面

台词是生活口语，不是书面语。带一点重复、一点磕绊、一点“那个”“这个”“你看”。不用成语，不用排比，不用金句体。

### 5.4 品牌植入藏进物品逻辑

带品牌合作的片子（美的、零跑、吉利、海尔、懂车帝、岚图），品牌不是插播广告，是物品本身：

- 21《习惯》：智能房子就是小美，习惯就是产品的逻辑。
- 22《条件》：懒人三件套就是“走出条条框框，做个懒人”的答案。
- 31《喜喜车》：懂车帝 328 项检测就是“没有一辆车是一模一样的”的证据。

**植入的红线：品牌不能替物品翻面。** 翻面的力必须来自物品本身（§3），品牌只能是物品的一个属性。23《租·购》和 25《回家》中段的硬推销（懂车帝/国补、五菱参数）是反例——推销段和剧情是两张皮。

## 7. 数字与重复：两个杠杆

### 7.1 数字

精确的数字锚住全片（§4.5）。数字越具体，越像真的。写的时候先定一个数字：多少天、多少钱、多少公里、第几辆、还剩几天。

### 7.2 重复

关键句重复多次，越重复越重（§4.6）。重复的不是同一句话的简单复制，是同一句话在不同处境下再说一遍，意思每遍都不一样。

## 9. 禁忌：什么不能写

| 禁忌 | 为什么 | 反例 |
|---|---|---|
| 说教 | 道理一讲出来，物品就死了 | “这个故事告诉我们，要珍惜眼前人” |
| 把人当主语 | 人一当主语，就不是以物喻人了 | “你这个人就是太贪心了” |
| 为反转而反转 | 翻面必须来自物品本身，不能靠剧情诡计 | 结尾突然说“其实他早就死了” |
| 煽情 | 哭、喊、跪、慢镜头配乐煽情，情绪一上来，物品就没了 | 两个人抱头痛哭三分钟 |
| 恐怖 / 惊悚 | 不是这个路子 | 跳吓、血腥、灵异 |
| 重复物品 | 一件物品只用一次（§2.3） | 再拍一集《假花 2》 |
| 硬插广告 | 品牌不能替物品翻面（§5.4） | 中段突然开始念产品参数 |
| 讲大道理 | 点睛台词说的是物品，不是格言 | “人生就是这样” |
| 把结局讲满 | 结尾要留一点，让观众自己接上 | 点睛台词之后再加一段总结 |
| 写自己没验证过的情节 | 没转写、没核实的不要写进正文 | 见附录 B |

## 10. 质检：三闸

交付前过三闸，不过不交。

### 闸一：物品闸

- [ ] 物品是日常、具体、已在场景里的吗？
- [ ] 这件物品以前用过没有？（查附录 A）
- [ ] 它的“毛病”找出来了吗？毛病就是它要说的人话吗？
- [ ] 翻面只用了物品本身的事实，没有借外面的道理吗？

### 闸二：对话闸

- [ ] 全片是对话吗？有没有旁白、解说、说教？
- [ ] 台词的主语是物品吗？有没有一句的主语是人？
- [ ] 推进靠问句吗？至少有三个问句吗？
- [ ] 有没有一句台词离开物品也能成立？有就删掉——那句不是这片子的。

### 闸三：结尾闸

- [ ] 点睛台词 ≤50 字吗？主语是物品吗？
- [ ] 点睛台词说完，前面所有对话的意思都变了吗？
- [ ] 结尾留白了吗？点睛台词之后没有总结吗？
- [ ] 简介和点睛台词不是同一句话吗？（简介是换一个说法）

## 11. 交付

### 11.1 交付物

1. **剧本**：场景 + 两个人 + 对话（只写对话，不写旁白）。时长 2–8 分钟。
2. **拆解**：中心物品 / 象征 / 结构 / 点睛台词（格式见 references/ 任一文件）。
3. **简介**：一句话点题（§6.3），不超过 30 字。

### 11.2 交付格式

剧本按以下格式写：

```
标题：《X》
场景：[一家店，柜台前]
人物：顾客 / 店主（老布）
物品：[一件日常物品]
点睛台词：[一句 ≤50 字，关于物品]

顾客：……
店主：……
……
店主：[点睛台词]
```

### 11.3 工作流

1. 定处境（§8 挑一个）→ 2. 定物品（§2 五条标准 + 查附录 A 查重）→ 3. 定点睛台词（§6 四条标准，先写最后一句）→ 4. 找物品的“毛病”（§2.2）→ 5. 写对话（§5，一问一答，至少三个问句）→ 6. 翻面（§3 三步）→ 7. 过三闸（§10）→ 8. 写简介（§6.3）→ 9. 交付。
