## 0. 六道锁：动笔前必须问清（缺一不可默认）

写之前先把这六项对齐。用户已明确的不问；没说的，用推荐默认值并**在交付说明里写明用了默认**。绝不静默跳过。

| 锁 | 取值 | 说不清时默认 |
|---|---|---|
| 语言 / 语域 | 中文简体 / 繁体 / 英文 / 其他 | 跟用户说话的语言 |
| 篇幅形态 | flash ≤1.5k / 短篇 3k–8k / 长短篇 8k–15k 字 | 短篇，4k–6k |
| 平台腔调 | 知乎盐言 / 番茄 / 七猫 / 黑岩 / 纯文学 / 不限 | 不限，走"宁烈不温"底座 |
| 视角 / 人称 | 第一人称（默认）/ 第三人称限知 / 全知 | 第一人称 |
| 目标情绪 | 意难平 / 反转震撼 / 爽感释放 / 治愈 / 细思极恐 / 共鸣 | 由题材反推，告诉用户我推了哪个 |
| 交付形态 | 单文件正文 / 正文+设定+大纲 / 带分节 / 带导语与付费点 | 单文件正文 + 分节 + 一句话交付说明 |

**素材形态 M1（默认）**：不索要参考图、不因缺图阻塞。用户给了对标语料或自己写的片段才用，没有就直接写。

## 1. 定情绪：先定读者读完的那一秒（Z）

**动笔前必须敲定一个目标情绪。** 不是"想写个悬疑"，是"读者合上手机时心里堵得慌"。

### 1.1 情绪六型与题材对应

| 情绪 | 读者体感 | 难度 | 常见题材 | 结尾落点 |
|---|---|---|---|---|
| 意难平 | 胸口闷，想骂人又想哭 | 中 | 追妻火葬场、错过的青春 | 余韵式、不回头的离开 |
| 反转震撼 | 后脑一凉，想重看开头 | 高 | 悬疑、身份错位 | 反转再反转、开放式 |
| 爽感释放 | 一口气吐出来，想转发 | 低 | 打脸、逆袭、复仇 | 金句式、碾压式兑现 |
| 治愈温暖 | 眼眶热但不掉泪 | 中 | 甜宠、亲情、救赎 | 呼应式、日常物件回扣 |
| 细思极恐 | 后背发凉，越想越怕 | 高 | 悬疑、民俗、规则怪谈 | 留最后一块拼图给读者 |
| 共鸣感动 | "这写的不就是我" | 中 | 世情、职场、婚姻 | 具体的家常细节收口 |

用户只给了梗没定情绪 → 我推一个，给理由，让用户点个头。

### 1.2 单一效果律（D 的 Poe 原则）

**动笔前用一句话写下这篇要制造的效果**，写在脑子里就行。之后每句话拿它称一遍：不服务这个效果的，写得再好也是垫字。

> 效果 = 目标情绪 + 具体载体。"让读者恨到牙痒"是情绪；"让读者在婆婆说'先过户房子'那一刻恨到牙痒"才是效果。

### 1.3 一句话梗概（A 的最后一针原则 + D 的 logline 配方）

**先写最后一句，再写第一句。**

- 最后一针（last dab）：写完要让人"只听这一句就想转发"。中文短篇里它就是截图传播的审判金句或漠视收尾。
- 第一句：题材承诺 + 一个具体赌注。
- 中间留空，用 BUT/THEREFORE 填。

```
第一句：{事件/对话/动作/信息炸弹}
最后一句：{审判金句 / 火葬场预告 / 漠视收尾 / 回扣物件}
```

## 2. 搭脊：一篇只有一个变化（D）

短篇不是缩小的长篇。它有另一套物理。

### 2.1 单一变化

**一个角色、一段关系、一个认知，只能变一次。** 选那条真正要变的主线，剩下全砍。

写完大纲后自检：如果我在这篇里能找出两个"人生转折"，那这篇就该拆成两篇，或者砍掉一个。

### 2.2 窄口径（硬指标）

| 项 | 上限 | 超了怎么办 |
|---|---|---|
| 有名有姓的角色 | 1–3 个 | 合并、改成"那个医生""我妈" |
| 时间跨度 | 几小时到几天 | 用一句倒叙把长前史带过 |
| 地点 | 1–2 个 | 一场戏换一个地方是浪费字预算 |
| 支线 | 0–1 条，且必须服务主线 | 砍 |
| 世界设定介绍 | ≤1 句 | 靠人物反应漏出来，不设说明书 |

每个新角色、新地点都要付"铺垫费"，短篇的字预算付不起。

### 2.3 MICE 线（可选，写复杂一点时用）

短篇通常只跑一到两条线：`人物`套在`事件`里，或者单独一条`探询`。
**开了的线必须按它的规则关掉**——5000 字的短篇里，一条没关的线就是读者看得见的洞。

- **Milieu 环境线**：进出世界即闭合（进得去、出得来）
- **Inquiry 探询线**：问题提出→答案给到
- **Character 人物线**：内在状态变化即闭合
- **Event 事件线**：外部秩序被打破→恢复

### 2.4 四个变量（P + D 的组合杠杆）

搭脊时把这四项各定成一个值，它们决定这篇的密度：

1. **关系变量**：这两人之间欠着什么？（钱、孩子、名分、一条命、一句没说出口的话）
2. **代价变量**：失败会失去什么？必须三级都具体——外部（丢什么）、关系（失去谁或谁的信任）、内在（变成什么人）。至少两级要具体到个人。
3. **信息变量**：读者比主角多知道什么（信息差）/ 比主角少知道什么（暗牌）？
4. **时间变量**：有没有倒计时？到期必须兑现，不许失踪。

## 3. 大纲：用 BUT / THEREFORE 连，不用 AND THEN（A + P）

### 3.1 铁律

**每两拍之间，连接词只能是 BUT（但是）或 THEREFORE（所以）。** 如果只能塞进 AND THEN（然后），这一拍就是废的，重写。

- 差：房租涨了，然后生源掉了，然后差点倒闭，然后试了免费课，然后爆满。
- 好：房租翻倍 → **所以**三个月就要关门 → **但是**晚上全空着 → **所以**试了一节免费体验课 → **但是**根本不知道会不会有人来 →（悬着）→ 一天订满十二对。

### 3.2 小节大纲表（Z 的五列，砍到最瘦）

| 在全篇哪一段 | 这节发生的事 | 情绪 | 节尾停在哪 | 目标字数 |
|---|---|---|---|---|

- **这节发生的事**：一句话写真实的改变。每节至少改变一项：证据归属 / 嫌疑判断 / 关系分寸 / 风险等级 / 读者理解。
- **节尾停在哪**：怎么接下一节。付费点那节标「付费点」。
- **情绪**：本节把读者放在哪个情绪刻度上。
- 没有变化的节 → 合并或删。

### 3.3 try/fail 升级链（D）

中段最容易塌。用这条链撑：

1. 第一次尝试失败（显而易见的办法不管用）
2. 第二次失败更惨（聪明的办法反噬，比之前更糟）
3. 第三次带来挫折或灾难（最多算局部进展，逼出下一场）

规则：
- **每次失败必须由这次尝试本身造成**，不能靠"碰巧倒霉"。读者要觉得主角自己把自己搞更惨。
- **巧合只能添乱，绝不能救场。** 天降神兵一次，读者就再也不信你的紧张感了。
- 两次失败之间插一个 Sequel（见 §4.2），让读者感到代价在涨，而不是噪音在涨。

### 3.4 场景结局四问（D）

每场戏给 POV 角色一个结局标签：

| 标签 | 含义 | 对压力的作用 |
|---|---|---|
| `yes` | 干净达成 | 泄压，少用 |
| `no` | 被挡住 | 维持 |
| `yes-but` | 达成但有代价或新麻烦 | 加码 |
| `no-and` | 没达成，而且更糟 | 加码最猛 |

一条典型的链：`no` → `no-and` → `yes-but`/`no-and`。**连三个 `yes`，故事就停止反抗了。**

### 3.5 情绪弧线六选一（Z）

| 走向 | 适合 | 转折与兑现怎么落 |
|---|---|---|
| 先压后扬（V） | 虐后翻盘、破镜重圆 | 压到退无可退再翻，留足反击与结算 |
| 先甜后崩（倒 V） | BE、信任崩塌 | 甜到最满处崩，跌比升快，结尾不加糖 |
| 几起几落（W） | 追妻拉扯、多反转 | 两三次起伏，峰逐次加重，终峰落在总清算 |
| 一路上扬 | 打脸爽文、层层揭秘 | 借阶段反制一路推高，大底牌留终局 |
| 憋到最后爆 | 隐忍复仇、身份揭秘 | 前段蓄压攒证据，终局集中引爆 |
| 最后急转 | 细思极恐、动机反转 | 前段常规推进，终局前亮出反常 |

选一种写进大纲，全篇照它起落，**不要求逐节递增**。

### 3.6 反转（需要时，Z 七型速查）

| 类型 | 用在哪 | 关键操作 | 最容易翻车的地方 |
|---|---|---|---|
| 身份反转 | 角色不是你以为的人 | 多处互相印证的行为细节泄露，禁叙述者直说 | 角色自报"其实我是……" |
| 视角反转 | 真相换个角度完全不同 | 叙述者所述皆事实，但不是全部事实 | 明知真相故意骗读者 = 作者作弊 |
| 动机反转 | 做这事的原因不是你以为的 | 前置微小矛盾行为，高压二选一暴露真因 | 前半按真意写，反转时偷换动机 |
| 时间线反转 | 顺序跟你理解的不一样 | 不撒谎，只调叙述顺序；用时态、季节、物品新旧埋线 | 时间戳对不上 |
| 信息反转 | 你掌握了错误信息 | 新证据直接否定旧"事实"，读者与主角同步被骗 | 前文毫无支撑 |
| 认知反转 | 你对整段关系的理解被颠覆 | 负面场景里埋正读不起眼、回看贯通的反向细节 | 先写无谓羞辱再强行洗白 |
| **无反转** | 甜宠/喜剧/报应型 | 走报应兑现或甜度递进，别硬塞 | 为了反转而反转，毁节奏 |

**嵌套**：最多 2–3 层，主次分明。每层走同一条链：`铺垫事实 → 当时的错误解释 → 触发证据 → 真相揭示 → 行动/关系后果`。第一层必须能暂时结案，第二层不仅要推翻它，还要解释读者当初为什么信。

### 3.7 反转自检三问

- **合理性**：回看前文能找到至少 2 处支撑线索吗？
- **公平性**：骗读者的是视角局限，还是作者撒谎？（红鲱鱼必须真推一段支线，不能只当幌子）
- **结算**：揭示之后还留了行动、关系变化或代价的空间吗？

### 3.8 伏笔回查

列结尾的关键元素（物件、信息、角色、关系变化），每一项前文都得有铺垫。选了"反复出现的物件"就用三次：铺垫段出现 → 反转段意义翻转 → 结尾回扣暴击。铺垫与揭穿之间隔开别的事件，别刚埋就揭。

## 4. 逐场铺页：把一秒钟写成一段（P + D + Z）

### 4.1 场景三维揉进（Z）——禁止按维度分段

写关键子事件时，从三处取有新信息的内容，**织进同一段**：

| 维度 | 内容 | 要点 |
|---|---|---|
| 发生 | 事情出现了 | 1–2 句，含一个具体细节 |
| 感知 | 主角注意到什么 | 只取会改变理解/判断/气氛的细节，不按感官凑数 |
| 反应 | 角色接下来怎么办 | 直接情绪、利害盘算、选择、台词或有后果的身体变化 |

❌ 三个维度各起一段 = 同一件事讲三遍。
✅ 我本以为他是真心道歉，可摸到那碗凉透的排骨汤时，心更冷了。上面浮着一层凝固的油，根本喝不了。

### 4.2 Scene / Sequel（D）——中段不再堆事故

**Scene（场景）= 目标 → 冲突 → 结局**
**Sequel（余波）= 反应 → 两难 → 决定**

不是每场都要余波。该写余波的时候：结局是挫折/灾难、主角被改变了理解、下一场需要一个有代价的决定。

- **反应**：身体的、不自主的，两拍就够，别铺一整页自我消化。
- **两难**：不是有标准答案的问题，是**两个都烂的选项**。写成显式提问 + 显式代价："交出地图就失去唯一优势，护着地图就让她答应保护的人走进埋伏——选哪个？"
- **决定**：必须是**他自己**做的，从他是谁推出来，而且**必须付代价**。不付代价的决定不算决定。

### 4.3 子弹时间：哪里必须写慢（P）

重要时刻要写得比真实时间慢得多。一个动作拆成"准备—执行—意外—调整—完成"，一秒钟写成一段。

**稀薄版（90 字）**：沈惊鸿拔剑迎上，连退三步挡住几招，趁对方换招，一剑刺向左边三寸，那人闷哼后退。

**放慢版（350 字）**：他右手早按上剑柄却没立刻拔——巷子太窄，横拔会撞墙，他需要一个半转身。第一刀是竖劈，刀锋落下来时他看清角度偏右两寸，说明对方左手持刀或者右臂有旧伤……（肩蹭粗石、虎口发麻、靴底积水打滑）……对手收刀回拉那一下，左肋露出约一息的空档。剑尖找过去像呼吸一样自然，他能分清布料、表皮、肌肉不同的阻力，三寸，够了，再深一剑就拔不回来。

**四个必须放慢的位置**：反转揭底那一拍、代价落地那一拍、告白/决裂那一句、发现关键证据那一瞬。
**其余位置一律快**：赶路、办手续、交代背景，1–2 句带过。

### 4.4 疏密分配（Z）

| 节点 | 笔墨 |
|---|---|
| 爽点 / 打脸 / 反转 / 情绪高潮 | 密：详写，感知动作对话铺满 |
| 铺垫 / 日常 / 关系升温 | 中：挑一两个有代入感的细节写实，其余略 |
| 过场 / 赶路 / 信息交代 / 时间跳转 | 疏：1–2 句带过 |

整篇要有推进与停顿。停顿可以是信息悬置、对话空白、等待或环境压力，**不要用微动作填空格**。

### 4.5 防注水判据（P）

字数不够时，先查已有事件是否略过了人物的**尝试、阻碍、选择与代价**，再考虑补细节。

**唯一判断标准：删掉这一段，故事会变差吗？** 答案是否 = 注水。

无效扩充清单：无关的风景、凑字数的回忆、换个说法重复已知信息、冗长的路程与等待、大量"嗯嗯啊啊"的寒暄。

### 4.6 开头：第一页必须交三样东西（D + Z）

按优先级：

1. **声线（Voice）**： unmistakably 这个人的叙述质感，不是通用旁白
2. **欲望（Want）**：他此刻、在这一页上，想要一个具体的东西（不是人生理想，是这场戏的目标）
3. **不稳定（Instability）**：有什么不对、被威胁了、要变了

**禁止开头三样**：地理（有人的问题之前先写风景）、前史（先讲背景再给赌注）、世界观（先讲系统再讲被系统伤的人）。

**中文短篇的"零环境规则"**：前三句不许出现不承载事件的环境描写（灯光、天气、气味、温度、装修）。前三句必须是：事件、对话、动作、规矩或信息炸弹。

**入场晚、退场早**：读者在争吵中途进来，在逃走的半路离开。

### 4.7 人物出场纪律（D）

1. 动作先行：第一次露面就让他在轻度压力下做一件有特征的事，绝不在静止状态被描述。
2. 及时命名：露面第一段内给出名字。有名无影、有影无名都让读者困惑。
3. 行为替代描写：外貌靠动作和别人的反应带出。一两个具体细节比整张肖像更狠。
4. 入场必须有后果：他的出现要带来新信息、新紧张或一个被迫的决定。入场毫无改变的，砍掉，改成早就在场。

### 4.8 节尾：停在答案出来之前（Z + P 十三式）

| 落点 | 怎么停 | 例 |
|---|---|---|
| 动作被打断 | 关键动作做到一半 | 绑匪举刀刺向我腹部，紧闭的房门突然被一脚踹开。 |
| 来人或来电 | 关键人物到场，或电话那头换了人 | 他的手机终于打通，接电话的却是派出所民警。 |
| 证据只亮一处 | 文件刚翻开，只亮最扎眼的一处 | 我翻开被改成意外的尸检报告，鉴定人签名栏里是我法医妻子的名字。 |
| 狠话或条件落尾 | 对方把话说绝 | 婆婆把病危通知书摔在我脸上："想拿钱给你妈治病，先把你名下婚房过户给你小叔子！" |
| 身份将揭 | 有人问出关键问题，或说漏一句 | 门外的大姐听见禁闭室里敲出的儿时暗号，脚步猛地顿住："里面关的到底是谁？！" |
| 主角留了后手 | 读者看见准备，对手还不知道 | 他叫私人医生打镇定剂封口时，我借着袖子遮挡按下了录音键。 |
| 后果预告 | 叙述者提前说这一步会出事 | 我冷着脸让讹人的租客趁早搬走，可我没想到，就因为这句话，第二天全网都在骂我是逼死穷人的恶房东。 |
| 心死定格 | 一句话从忍让切到决裂 | 看着他护在白月光身前的背影，我心里最后一束光也熄了。 |
| 异常出现 | 不该动的东西动了 | 我把女儿的洋娃娃锁进柜子，刚转身，背对我的娃娃脑袋咔哒一声转了过来。 |

**节尾禁忌**：假悬念（威胁不存在，下节开头秒解）、巧合解围、连续几节不给任何信息、用无关小事造悬念、连着用同一种手法问同一个问题。

**节首接法**：第一句接住上一节留下的问题——写那一下的结果、谁的反应、对白的回应。要跳时间/换地点，一句交代完就进事件。

### 4.9 对白：只说会改变东西的话（Z + H）

只保留会改变**信息、策略、权力、关系或行动**的台词。

- 对话独立成行，不嵌在叙述段里。
- 少用"他说""她道""他笑了笑说"，用顺手动作带出；普通的"说"按语境留。
- 两人连续对话省略标签，靠内容区分说话人。
- **潜台词是分水岭**：真人不会把感受说得清清楚楚。分歧靠回避、换话题、身体语言表现出来，不靠直接陈述。**最好的对话，是那场从头到尾没说出真正议题的对话。**
- 打脸/审判场景可以密；抒情、心死、核证、等待、悬疑观察场景可以少或没有对白。

### 4.10 节奏：念出来顺不顺（A + H）

- 中文手机阅读：短段、完整句为主，句子常在 20 字上下按意思停顿。
- **锯齿边缘测试**：每句换行排下来，看左边缘。句尾参差不齐 = 长短有变化，好；全都停在差不多同一个位置 = 单调，拆长补短。
  ```
  卖光了。
  一对对情侣喜欢得不行，两个人在一个轮子前弄得满身泥，笑得停不下来。
  于是我又加了几场。
  ```
- 三连排比：有功能的递进/枚举保留，只砍无信息量的纯修辞凑数。
- 相关动作连起来写，不拆成三五字的碎句。碎句只留给钩子、反转和情绪峰值。
- **可信 > 清楚 > 具体 > 有声线 > 有风格**。绝不为风格牺牲准确。

## 5. 三闸质检

写完必过。blocking 的必须改完才能交。

### 闸一：结构闸

- [ ] 目标情绪只有一条，且每个高光时刻都在为它服务
- [ ] 只有**一个变化**；没有第二个"人生转折"混进来
- [ ] 角色 ≤3 个有名有姓，地点 ≤2，时间跨度 ≤几天
- [ ] 每节至少改变一项（证据/嫌疑/关系/风险/读者理解）；没有变化的节已合并或删
- [ ] try/fail 至少两级失败，且每次失败由尝试本身造成，巧合没救过场
- [ ] 场景结局里没有连续三个 `yes`
- [ ] 反转（若有）回看有 2 处以上支撑；揭示后留了结算空间
- [ ] 结尾元素（物件/信息/关系）前文都有铺垫
- [ ] 字数落在锁定范围

### 闸二：句子闸

- [ ] 前三句是事件/对话/动作/规矩/信息炸弹，没有纯环境
- [ ] 第一页交出了声线 + 欲望 + 不稳定
- [ ] 每段只有一个画面变化或一条连续的推理/情绪链
- [ ] 爽点、反转、峰值处是密的；过场是疏的
- [ ] 子弹时间只用在四个位置，其余都快
- [ ] 对话独立成行，引号统一，没有机械标签
- [ ] 句长有锯齿，不是同一节奏一路平推
- [ ] 删掉任何一段，故事都会变差

### 闸三：AI 腔闸（H + A）

**先诊断，再修。** 五种病灶，念出来就听得见：

| 病灶 | 长什么样 | 怎么治 |
|---|---|---|
| 空泛压缩 | "用户很沮丧" | 换成具体实例："用户点了六次导出，因为什么都没加载出来" |
| 意义膨胀 | "这是一个关键的转折点" | 陈述事实，让读者自己称重量 |
| 骑墙表态 | "可以说……也许……" | 要么站定，要么删句 |
| 节奏平板 | 每句一样长，每段三句 | 破拍子 |
| 借来的权威 | 像麦肯锡 PPT 或 LinkedIn 鸡汤 | 改成你会跟一个人当面说的话 |

**具体性阶梯**（至少要到第 3 级）：

```
模糊：那家公司遇到了挑战。
具体：那家公司现金流出了问题。
具象：那家公司半年里拖欠了两次工资。
长在身上：三月工资跳票，八月又跳了一回。CFO 是从 Slack 上知道的。
```

**头号病症：否定平行结构**（"不是 X，而是 Y"）。这是最像 AI 的单一标记。

- 全家族：不是A是B / 少一点X多一点Y / 别想X要想Y / 真正的问题不是X是Y / 表面上X其实Y / 大多数人以为X，其实Y
- 修法：**删掉被否定的那半句，把肯定句改成带具体细节的直接主张。**
- 例外：B 具体（到第 3 级：实例、数字、机制）+ 正文真的兑现了它 = 允许（钩子和标题常用这种反差）。B 是"心态""体系"这种空词 = 立即砍。

**其余高频信号**（出现不是错，回上下文看有没有功能）：

| 信号 | 例子 | 判断 |
|---|---|---|
| 情绪贴标 | 她感到愤怒 / 一丝悲伤涌上心头 | 峰值时刻要演出来，过场可以直接说 |
| 盖章通告 | 嘴角勾起、眼中闪过、瞳孔微缩、指节泛白、深吸一口气 | 连刷扎堆 = 换人也能套的橡皮图章动作，改成这个人才会做的事 |
| 认知结论链 | 她这才意识到 / 他终于明白 / 这意味着 | 重复读者已经得到的意思 |
| 抽象收束 | 命运的齿轮、从这一刻开始、属于她的反击才刚刚开始 | 只宣告分量，没有实际影响 |
| 万能比喻 | 如潮水般、像被抽走了力气、仿佛整个世界失去了颜色 | 换场景也能用的比喻 = 没功能 |
| 论述腔 | 不难看出、事实上、与此同时、机制、逻辑、体系 | 和人物、年代、载体不搭 |
| 告知式心理 | 他知道这一切都来不及了 | 用他做了什么来替代 |

**标点规范**：中文叙述旁白不用破折号 `——`（对话内被打断或拖音可用）；`……` 用于对话、面板和偶发停顿，旁白禁连刷；禁 `!!!`；一段里别每句都以 `？` 结尾。

**词表不是检测器**（H）：所有"AI 高频词清单"都不靠谱——跟模型版本、提示词、题材全有关。把它当编辑口味用，别当身份判定。

**卖点保护**（Z）：强情绪写法（直写心死、审判金句、火葬场预告、苦难排比）是题材承诺，**按功能判断，不当 AI 腔一律删**。该压的是同义复述，不是情绪本身。

## 6. 交付

### 6.1 交付说明（白话，不报脚本名不报字段名）

1. **写了什么**：标题、一句话核心钩子或反转、总字数、几节。
2. **需要你拍板的**：每件写成一个问句 + 我的推荐默认（例："结尾要不要再加一个小反转？默认不加"）。没有就省略。
3. **自查一句**：字数、分节、常见 AI 腔过了/没过，差多少。

### 6.2 交付清单

- [ ] 正文按平台腔调分节，格式统一（段间单换行，不加空行缩进，正文内不用 Markdown 符号）
- [ ] 字数落在锁定范围，没落进去就不算写完
- [ ] 三闸全过
- [ ] 交付说明三段齐全

### 6.3 一句话交付原则

**宁短一截，不乱一段。字数不够只扩写已有情节点，超了只压重复解释，不靠增删剧情凑数。**
