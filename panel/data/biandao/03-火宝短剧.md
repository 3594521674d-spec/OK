## 它是干什么的

火宝短剧，一句话生成完整短剧、从剧本到成片全自动化。技术栈 Nuxt 3 + Hono + Mastra，4 个 Agent：script_rewriter（剧本改写）、extractor（角色场景道具提取）、storyboard_breaker（分镜拆解）、prompt_generator（提示词生成）。视频走 Seedance 2.0 / MiniMax H3 / Wan 3.0；FFmpeg 单镜头合成 + 整集拼接；`@角色名` 自动映射参考图；批量生成 + 失败一键重试；v4.0.0 有 Electron 桌面版 + SQLite。

## 编导环节具体怎么写

来源文件：`backend/workspace/skills/` 下 extractor、script-rewriter、storyboard-breaker、prompt-generator 四个技能的 SKILL.md。

### 剧本改写（script-rewriter）
- 五条改写原则：保留核心情节；增强画面感（叙述性文字转成可视化场景描写）；对话驱动（用对白推动情节，减少旁白）；节奏把控（每场戏 30–60 秒）；**不写镜头语言**（景别、角度、运镜一律不写，那是分镜步骤的事）。
- 格式化剧本格式：`## S01 | 内景 · 咖啡厅 | 黄昏` 做场景头；动作描写自然段；对白写 `角色名：（状态/表情）台词内容`。
- 心理描写可转化为角色表情/动作或画外音；长段叙述拆成多个短场景；每个场景有明确的情绪转折点；时间段要具体（黄昏、深夜、清晨），不要笼统写“白天”。

### 角色、场景、道具提取（extractor）
- 角色提取字段：name（必填）、role（主角/配角/龙套）、appearance（样貌 300–500 字：性别、年龄感、五官、体态、气质）、styling（妆造：发型、服装、妆面、配饰）、description（背景故事和人物关系）。**性格特点不要单独输出，要转化为外在气质与神态融入样貌描写**（例如“性格冷峻”写成“眼神冷峻、表情克制、少有笑意”）。
- 场景提取字段：location（必填）、time（时间段，同地点不同时段视为新场景）、prompt（空间、陈设、年代质感、关键视觉元素，纯背景不含人物）、lighting（光源、色调、明暗、氛围）。
- **道具提取核心原则：宁可少提，不要多提。** 道具是用来生成白底单品图、供视频特写引用的高成本资产，只有剧情关键道具才值得提取。一集通常 0–3 个关键道具，超过 3 个按剧情重要性只保留前 3 个。
- 道具必须同时满足两条，缺一不可：① 直接推动剧情（出现、交接、损坏或发现会引发情节转折）；② 值得单独生成图片（后续分镜会给它特写或反复出现，需要固定外观）。
- **判定三问**，任一答“否”即放弃：① 删掉它剧情是否依然成立？成立则不提取；② 它只是角色随手使用的日常物品吗（手机、筷子、水杯、香烟、雨伞）？是则不提取；③ 它是场景陈设的一部分吗（桌椅、灯具、门窗、挂画、餐具）？是则不提取。
- 去重规则：角色/道具按名称精确匹配，场景按精确匹配，命中的优先复用，不要重复创建；近名去重按括号前主体比较。

### 分镜拆解（storyboard-breaker）
- 核心定义：一个分镜 = 一个分镜段落 = 一个视频生成任务。每个段落 8–15 秒，内部承载 2–4 个子镜头；子镜头之间可以切镜（换景别、换角度、换拍摄对象，用硬切衔接）；**子镜头之间不跨场景**（一个段落只发生在一个场景内）。
- 拆分四步：读剧本与已有资产 → 节拍识别（开场、触发、高潮、收尾，**节拍边界强制切段**，不把一条因果链铺垫-发生-反应切散到不同段落）→ 总量锚定（目标总时长 = 剧本字数 ÷ 500 字/分钟；段落数 ≈ 目标总时长 ÷ 12 秒，允许 ±20% 浮动）→ 段落内拆子镜头。
- 节奏分层时长：过渡段 8–10 秒，叙事段 10–15 秒，爆点段 12–15 秒（特写、规则揭示、情感爆发、反转；子镜头节奏放慢，单个子镜头可停留 4–6 秒）。
- **台词时长下限（硬规则）：段落时长 ≥ 段内台词与旁白总字数 ÷ 4.5 字/秒 + 2 秒表演余量。** 装不下的台词必须拆到下一个段落，不允许把演不完的台词塞进一个段落。
- 段落字段：镜头标题（3–5 字）、时间（具体时分 + 光线）、地点（完整描述 + 空间布局 + 环境细节）、景别、角度、运镜、画面描述（按逐子镜头写观众实际看到和听到的，画面在前；有台词写「角色名说：「台词」」，旁白写「旁白：内容」）、画面结果（段落结尾的即时后果 + 视觉细节）、氛围、时长、场景关联、角色关联、道具关联。
- 道具绑定规则：道具被角色使用、交接、特写，或在画面中明显可见且对叙事有意义时，必须绑定到段落；绑定的道具会作为视频生成的参考图（白底单品图），保证道具外观跨段落一致。

### 提示词生成（prompt-generator）
- 角色最终提示词（character-prompt）：一张角色设定参考图，构图固定为**左侧正脸特写 + 右侧正面/90 度侧面/背面三张等高全身视图**，头顶与脚底对齐。核心原则：**一致性 > 美观**，中性、清晰、可复用，不要追求单张图的艺术感。描述顺序：身份锚点（年龄感、性别感、体态）→ 五官（脸型、眼睛、疤、痣、眼镜）→ 发型 → 服装 → 配饰。禁止：动态姿势、夸张表情、手持道具、与他人同框、裁切身体、文字水印、重阴影、彩色背景光。风格词不由提示词写，由工具自动注入到最终提示词最前方。
- 视频提示词（video-prompt）：第一行是信息头，先介绍这条视频有哪些人物和场景，再接时间分段；人物、场景一律用 @ 引用（生成时替换为对应参考图片标记）。按 3 秒为一段，每段单独一行，时间范围连续衔接，无重叠、无空缺。每个映射为 1–2 个连续的 3 秒段，顺序一致，不遗漏、不合并、不新增子镜头。第一段必须建立空间。切镜后的段开头用“切到/切回”衔接词，并重新交代景别与主体。情绪全部转为可见描写，不要“他很伤心”这类抽象词。**每段至少一个 @ 引用锚定画面**；角色出场的段必须 @ 该角色。

## 咱们缺什么

1. **道具提取三问**：咱们的 D 卡没有“宁可少提、不要多提”的门槛，也没有一集最多 3 个关键道具的上限。《伞》里伞是核心道具没问题，但以后多道具的剧容易把随手物品都做成资产卡，浪费生成次数。
2. **台词时长下限公式**：段落时长 ≥ 台词总字数 ÷ 4.5 字/秒 + 2 秒表演余量，比咱们的 4 字/秒更具体，还带了 2 秒余量。
3. **节拍边界强制切段**：咱们的 15 秒分段是按时长切的，没有“不把一条因果链切散”的明文。
4. **角色提示词“一致性 > 美观”**：咱们的三视图已经是这个思路，但没有写成一条明文原则，也没有“风格词由工具统一注入、提示词正文不写风格词”的分工。
5. **视频提示词信息头 + @ 引用锚定**：咱们的视频提示词开头没有“出场人物/场景”信息头，也没有“每段至少一个 @ 引用”的硬要求。

## 采纳建议

- P1、P2、P3 直接采纳：道具三问进 D 卡规则，台词时长下限公式进分段规则，节拍边界强制切段进分镜规则。
- P4 写进资产总则一句话。
- P5 部分采纳：咱们的投喂稿已有上传顺序（@图片 1、2、3……），信息头可以简化成一行“出场人物/场景”，不照搬它 3 秒一段的写法（咱们是豆包 15 秒一段，段内镜头按镜号写）。
- 不采纳：4 Agent 全自动流水线、Electron 桌面版、FFmpeg 自动合成（咱们手工出片、手工拼）。
