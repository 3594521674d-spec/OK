## 卡型体系总表

资产层的唯一目标是「锁住形象一致性」，不是把图出到好看。每类卡都对应一个**在后续镜头里会被反复引用**的视觉事实：是谁、是什么、在哪、什么状态、什么调子。出卡顺序固定为 **STYLE → P → D → S → FX**（定调图先出，人物先于道具，道具先于场景，特效最后）——后面的卡能吃到前面的调子，反过来不行。

| 卡型 | 编号 | 一张卡是什么 | 固定版式 | 图面文字 | 必填字段 | 什么时候出 |
|---|---|---|---|---|---|---|
| **STYLE 定调图** | STYLE01 / STYLE02 | 全剧调色与质感的唯一权威 | 单张空镜或半身景，非分格 | 无 | 画风句、色温、主辅色、材质词、负向词 | 第一张，永远最先出；有「今生/前世」双调或多时间线时出两张（STYLE01 正常调、STYLE02 低饱和冷调） |
| **P 人物卡** | P01（P 前缀 + 两位序号） | 一个角色的一组图：三视图 + 表情四态 + 服装卡 + 状态卡 | 三视图 16:9 横板；表情/服装/状态 9:16 竖张 | 三视图板**零文字**（角色板纪律） | 人物描述、三视图、表情四态、服装卡、状态卡、一致性锚点 3–4 个、音色（Voice Description + 图底速览标签）、固定负向词 | 人物首次出场前；配角可用表格一行三视图提示词降级处理 |
| **D 道具卡** | D01 | 一个道具的四格板 | 1:1 默认；高大物体 9:16；车辆/大型物件 16:9 | **保留**左上角道具名与格内标注（道具卡不受角色板零文字约束） | 尺寸、结构连接关系、材质与使用痕迹、状态卡、使用集数、正反面对应 | 道具首次被认出来之前；一次出全主卡 + 状态卡 |
| **S 场景卡** | S01 | 一个空间的一张母版 + 一张九宫格 | 母版 9:16 或 16:9 按 B 锁；九宫格 3×3（全图共 9 格） | 九宫格须带格号 / 图外对照表（中文渲染失败时降级为编号） | 母版 + 九宫格 8 字段（见 §三） | 场景首次使用前；同一地点的不同区域分别编号（客厅 S01、办公室 S02、婚纱店 S03） |
| **FX 特效卡** | FX01 | 一个可复用特效元素 | 单主体 + **纯黑背景**（方便后期合成） | 无 | 提示词要点、出现时机、使用集数 | 只在重生瞬间、前世闪回转场等需要复用特效时出；手机界面、文件文字一律后期做，不建卡 |
| **背影卡**（可选） | PB01 / 独立编号 | 只有背影或局部、不出正的「身份未揭」人物 | 9:16 竖张，背面全身 | 无 | 服装轮廓、体型、发型重量、标志物 | 悬疑/身份反转题材，角色在揭面之前的所有镜头统一用这张，**不得顺手给正脸** |

**配角降级规则**：不承担跨集识别任务的配角不建 P 卡，在资产库表格里写一行三视图提示词即可（同前缀 + 外貌全文 + 正面/侧面/背面同排 + 全身 + 16:9 横）。**判据**：这个角色有没有「换张脸观众会出戏」的镜头——有就升 P 卡。

**命名规则**：`资产类型_编号_状态_集数`，如 `人物_P01_今生通勤装_E01`、`场景_S02_办公室夜景_E07`、`道具_D01_婚戒_破损态_E12`。状态码（LOOK-A / LOOK-B）与编号必须同源：资产库里叫 LOOK-B，分镜里引用的也必须叫 LOOK-B。

**全剧共用的前缀**（风格词三处一致，用户改风格时三处一起换）：

```
人物前缀：<题材风格句>，电影级2.5D动画质感，成熟写实动漫比例，细腻五官与发丝，
         真实服装面料，柔和均匀的影棚光，中性浅灰纯色背景
道具前缀：<题材风格句>，电影级2.5D渲染质感，单主体居中，真实材质与使用痕迹，
         45度俯视，柔和影棚光，中性深灰纯色背景，无品牌标识
场景前缀：<题材风格句>，电影级2.5D环境绘制，真实空间透视与纵深，无人物，
         无品牌标识，<画幅>构图
```

## P 人物卡模板

一张 P 卡 = 一组互相独立、但都指向同一个「根」的图。**根是三视图板**，其余全部由它派生（见 §六）。

### 1 人物描述（先写文字，再写提示词）

七要素齐全，缺一项就会在生成时被模型自行补造：**年龄 · 气质 · 身高 · 头身比 · 脸型五官 · 发型发色 · 不变锚点**。

- 头身比必写：写实写「真人 6.5~7.5 头身」，3D/2D 按风格写对应值——这是防「头大身小」的第一道锁，与「头部完整入画」配套生效。
- 女性角色写具体的脸型、眼型、鼻唇，用「自然野生眉、素颜感、真实皮肤纹理」，**不写**「顶级美貌 / 精致立体 / V 脸」，负向词加「假体鼻、整容脸」。
- 具体到可画的颗粒度：「左眉尾一道 2cm 旧疤」「耳垂一枚极小的银钉」可以；「气质清冷」不够，要落到可画的形体——「下颌线偏窄、唇形薄、说话时左眉不动」。

### 2 三视图规格（根图，16:9 横板）

```
<P 卡编号> <角色名> 三视图
人物前缀 + 人物描述全文 + 一致性锚点全文
版式：正面 / 90°侧面 / 背面 三视图同排等距排列，同一比例尺，头顶与脚底对齐同一水平线；
     全身完整入画——头顶至鞋全部在框内（不裁头、不裁脚、鞋在格内画完）；端正站立，无 pose；
     只呈现人物本体与身上穿戴配饰，不手持任何独立道具（道具走 D 卡单独出图）
画幅：16:9 横构图
负向词：<见 §P.6 固定负面词表>
```

硬性五条：

1. **只出四格**（三视图板内：正面 / 90°侧面 / 背面 + 一张面部特写）；**不设独立大主图**、同一视角不得重复、不得出现第 5 格。写成「主图 + 四格板」会被模型出成 5 格、正面画两次。
2. **单一面部锚点**：全图只允许一张可辨识的脸，且必须落在「面部特写」格；其余三格一律**「无脸」——头部完整入画（不裁头、不砍头，保头身比）、面部不刻画五官**。用户口中的「打马赛克」必须转译成「无脸」，**禁止**字面写 `mosaic / pixelated / 马赛克 / 打码 / 无头 / headless`。
3. **零文字**：不标视角名、不标角色名、不标编号、不标脸部处理，不加边框文字/水印/logo/角标。唯一例外见图底细节条（§P.5）。
4. **提示词必须要显式声明「全图共 4 格」**，开头即写格数——不写格数模型就做加法。
5. **不写跨条引用**：一条提示词的投喂单位是它自己，「同上 / 见母版 / 同前 / 按上述」一律展开写死。

### 3 表情四态（9:16 竖张）

选最能代表这个人物的四种情绪，**不要四张都笑**。建议四槽位：**常态（基准）/ 受压（忍）/ 爆发（狠）/ 示弱（软）** 或题材替换为 **冷笑 / 惊恐 / 落泪 / 咬牙**。每种一张 9:16 胸部以上特写。

```
<角色名> 表情卡 · <情绪名>
人物前缀 + 外貌全文 + 一致性锚点 + 画风句
版式：胸部以上特写，正面略偏 3/4 角（3D/仿真人禁「特写×平视正面」组合——平贴脸出片无纵深、塑料感、易恐怖谷）
表情：<一个词的定性 + 2–3 条可画的肌肉/呼吸动作，如「下颌绷紧、鼻翼轻张、下唇微收」>
画幅：9:16 竖构图
```

- 表情必须落到**可见的形体**，不写「悲伤地看着镜头」这类语义指令。
- 同组表情卡共用同一句画风句与同一句光色，禁一张冷光一张暖光。

### 4 服装卡（每套一张 9:16 全身立绘）

```
<角色名> 服装卡 · <套装> · 使用集数 E01–E05
人物前缀 + 首部/脸部描述（与根图一致，不改脸）+ 服装全文 + 一致性锚点
服装：上装（版型/面料/颜色/纹样）+ 下装 + 鞋 + 配饰（逐件写清材质与位置）
版式：全身立绘，端正站立无 pose，头部至鞋完整入画，只穿不持物
画幅：9:16 竖构图
```

- **必须标注使用集数**（`使用集数 E01–E05`）。跨集延续时写「与第 X 集『角色名』实际参考图服装完全一致，以实际参考图为最终权威，不重新描述」。
- 服装卡是**派生图，只参考根图**的三视图板，不参考上一套服装卡。

### 5 状态卡（受伤 / 前世今生 / 妆造阶段）

```
<角色名> 状态卡 · <状态名> · 使用集数 E07 起
人物前缀 + 脸部描述（与根图一致）+ 状态描述
状态：<受伤位置与程度 / 妆造差异 / 精神状态，只写可见变化，不改骨相与五官比例>
版式：9:16 竖张，与服装卡同机位（便于对照）
```

三条纪律：

1. **前世和今生不能混**：两条时间线各建 LOOK-A / LOOK-B，写明外观与使用镜头，不得一张卡同时承载两个时代。
2. **受伤只进不退**：同一伤情在后续集只能加重或不出现，不能自愈；伤情卡按集拆分（`_伤轻` / `_伤重`）。
3. 妆造阶段（如「落魄期 / 翻身期 / 决战期」）各一张，状态码与分镜引用严格对应。

### 6 一致性锚点（3–4 个，全文重复出现）

锚点是**这个角色独有的、每张图都写一遍的不变量**，不是形容词。合格锚点：

- 一道特定位置的疤（「左眉尾一道 2cm 斜疤」）
- 一件不摘的配饰（「右手腕细银链，坠一枚小米粒大的黑珠」）
- 一个固定的发型细节（「额前右侧固定一缕碎发，其余头发低马尾扎紧」）
- 一个体型特征（「右肩比左肩低约一指」）

不合格：「清冷气质」「眼神凌厉」「五官精致」——画不出来，也核不了。**锚点必须逐字写进三视图、表情卡、服装卡、状态卡四类图里**，否则派生图会漂。

### 7 音色（有对视听的都写）

三件套，只有第 2 项进图：

1. **Voice Description（完整版，2–4 句英文，纯文本交付，不进图）**——给配音 / TTS / 下游用。例如：`Warm mid-low female timbre, ~28 y/o. Speech is measured with clipped endings; slight breathiness on soft consonants. Never shrill; anger reads as lowered volume, not raised pitch.`
2. **图底音色速览标签（≤8 词英文，渲染在图底部，全图唯一允许入图的文字）**——照抄 Voice Description 提炼后的短语，如 `warm mid-low, clipped endings, quiet anger`。
3. **图底声纹波形条**（非文字图形，属图案，不占入图文字名额）——视觉一致性锚，**不宣称能锁声线**（声线锁定走音频侧 TTS 音色 ID / 参考音）。

术语正名：图底那行英文是**音色交接文本**（timbre，听起来什么样），**不等于声纹**（voiceprint，指的是这个人是谁）。

### 8 固定负面词表（完整照抄，每次一字不改）

```
多余手指，肢体扭曲，多余人物，五官扭曲，比例失调，头大身小，Q版，卡通，真人实拍，
塑料皮肤，磨皮滤镜，网红脸，锥子脸，欧式大双眼皮，美瞳，假体鼻，整容脸，品牌标识，
文字，水印，logo，复杂背景，不同的人，第五格，重复的正脸
```

- 英文出图时对应：`extra fingers, distorted limbs, extra people, deformed face, wrong proportions, big head small body, chibi, cartoon, photoreal live-action, plastic skin, beauty filter, instagram face, sharpened chin, brand logo, text, watermark, different face, fifth panel`。
- 结构性负向词必须写：`fifth panel`（防 5 格）与 `different face`（防换脸），这两条是角色板唯一的机械可查项。
- 负向词与正向写法冲突时以正向为准：模型对否定不敏感、对词根敏感——被禁概念的词根不许出现在任何位置，改用不含该词根的正向描述。

## S 场景卡模板

一个场景 = **两张必出的图**：**母版（第一张）** 定空间结构与光向，**九宫格（第二张）** 定九个视角的取值区间。两类都要出、互不替代。

### 1 场景母版（必出第一张）

```
<S 卡编号> <场景名> 母版
场景前缀 + 空间描述（面积、层高、进深方向、主结构：门/窗/楼梯/主家具的方位与相对关系）
光源：光从哪个世界方向来（「东侧落地窗」而非「左侧光」），色温与光比
版式：无人物空景，一点透视或两点透视，视线高度 1.5m 左右
画幅：按 B 锁；九宫格与母版同画幅
负向词：人物、人影、动物、品牌标识、文字、水印、镜像重复
```

母版的作用是给后续所有镜头一个**统一的坐标系**：门在哪、窗在哪、光从哪来。分镜里的每个机位、每次反打，都要能回溯到这张母版的方位。

### 2 九宫格 8 字段（逐字段说明与示例）

九宫格 = **纯场景无人，一槽 = 9 视角**。8 个字段缺一即视为未按模板执行。

| # | 字段 | 写什么 | 示例（示例场景：宋府正厅 S04） |
|---|---|---|---|
| 1 | **场景定位** | 一句话说清这是什么空间、什么年代、什么体量；后接全图格数声明 | 「宋府正厅，北宋官宦人家，面阔五间、进深三丈，全图共 9 格。」 |
| 2 | **九宫格内容分配** | 先选模式 A（正交视图矩阵：正/侧/背/俯视/正视/反打等九机位）或模式 B（叙事视角矩阵：主视角/次视角/入口视角/局部/远景等），再逐格写出每格拍什么 | 「模式 A。格1 南向正视全景；格2 东西向侧视；格3 北向反打；格4 45° 俯视全景；格5 主座特写方向；格6 门槛入口视角；格7 檐下仰视；格8 西次间看主座；格9 东次间看门。」 |
| 3 | **参考场景锁定模式** | 有母版图时挂「锁参考图」开，档位 0.7–0.85；跨集延续时写【延续拍摄声明】+【参考图锁定】 | 「锁参考图：开，强度 0.8，参考图 = S04 母版。」 |
| 4 | **摄影机矩阵** | 按空间类型（室内中小 / 室内超大 / 室外半封闭 / 室外开阔）选定九机位组合；**统一 50mm** 摄影参数，不逐格换焦段 | 「室内超大：格1–3 为三面正交全景（50mm，1.5m 视高），格4–5 为俯视（50mm，3.5m 高），格6–9 为人视角局部。」 |
| 5 | **场景画面描写** | 每格能看到的结构、家具、陈设、材质、磨损痕迹；同一样东西在九格里描述必须一致 | 「青砖地面有常年踩踏的磨痕；主座为紫檀圈椅，椅背搭深青暗花椅披；梁下悬两盏纱灯，灯罩泛黄。」 |
| 6 | **光照与曝光控制** | 用世界方向定义光（东侧窗/头顶灯/门洞逆光），写光比与色温；九格共用同一套光 | 「主光为南向门洞自然光，右侧廊窗补光，光比 1:3，色温 5200K，暗部保留细节不过曝。」 |
| 7 | **画面标注要求** | 格号 1–9 与图外对照表；中文字渲染失败时**降级**为纯数字编号，不追求中文标题 | 「每格左上角标数字 1–9，图下附对照表；若中文渲染失败，只保留数字，不重试中文。」 |
| 8 | **风格分支** | 写实 / 2D / 3D 三选一，并把该分支整段抄进提示词；质感词须与 STYLE 定调图一致 | 「3D CG：电影级 2.5D 环境绘制，真实空间透视与纵深，木石材质颗粒可见，无体积雾滥用。」 |

九宫格的硬性条款：

- 必含【场景定位】【九宫格内容分配】【参考场景锁定模式】三块 + 「全图共 9 格」字样 + 锁定档正文 + 标注降级条款。
- **场景图必须无人**：禁止人物、人影、动物入画（除非用户显式声明）。
- 场景卡固定 16:9（资产板不随 B 锁成片画幅变）；母版与九宫格同画幅。
- 复杂场景另加**机位调度版 / 战斗站位版**（带人物与站位），与母版、九宫格三者互不替代。
- 墙角、桌面这类局部**不建空景卡**，参考行直接挂 D 卡或剧情机位卡。

## D 道具卡模板

### 1 四格板（全图共 4 格）

```
<D 卡编号> <道具名> 道具设定图
道具前缀 + 尺寸与结构（长宽高、各部件连接关系、开启方式）+ 材质与使用痕迹
版式：全图共 4 格 —— ① 正面视图 / ② 45° 侧视图 / ③ 顶部俯视图 / ④ 关键细节特写
     不设独立大主图，同一视角不得重复，不得出现第 5 格
标注：左上角标注「<道具名>」，格内可标注部件名（道具卡不受角色板零文字约束）
画幅：默认 1:1；高大物体 9:16；车辆/大型物件 16:9
负向词：人物，手，肢体，剪影，手持展示，品牌标识，文字水印（除道具本身文字）
```

四条禁令（与角色板同源病灶）：

1. 提示词必须显式声明「全图共 4 格」并写出四格原名。
2. **不设独立大主图**、无视角重复、无第 5 格。
3. **保留**左上角道具名与格内标注——不要被角色板的「零文字」纪律误删。
4. **无人物 / 手 / 肢体 / 剪影入画，无手持展示**（道具不能拿在手里出图）。

### 2 正反面逻辑（有结构道具的必写项）

书、信、手机、显示器、电脑、门窗、贴纸、壁画、证件、牌匾——凡**正反面或多角度差异明显**的道具，四格里必须让正面与反面都出现，并在提示词里写清对应关系：

```
正反面逻辑：① 格为封面（正面），② 格为展开内页（背面/内面），
           两面纹样与磨损必须对应同一件实物；折痕、污渍位置在正反面衔接处连续。
```

- 视频层引用时，从四格里挑「正面图或反面图」适配客观逻辑，不要让模型自行翻转（翻转出来的镜像文字/纹样是穿帮大户）。
- 有结构的道具写清连接与尺寸：「抽屉与柜体的榫接方式」「戒圈内径 17mm、镶口高出戒面 2mm」；不写尺寸就无法在多视角里保持一致。
- **状态卡**（破损 / 沾血 / 缺角 / 被烧焦）单出一张，标注状态与使用集数；状态变化**只能单向推进**（完好 → 破损 → 更破损）。

## 锚点图一致性铁律

参照 shuohao character-refs 的实测结论：**H3 只给正面全身，服装和背影都对，但脸会走样；加一张大头照，脸最接近。** 所以派生图不是可选项，但派生的**方向**必须严格单向。

### 1 一组图只有一个根

每角色一组图 = **一张根图（正面全身锚点 / 三视图板）+ N 张派生图**。根图是唯一的一张**文生图**，其余全是「根图 + 一句改图指令」。

### 2 派生只参考根图

表情卡、服装卡、状态卡、45° 大头照、细节图——全部**只参考根图**，不参考彼此。

### 3 禁止连锁

```
✅ 正确：P01 三视图（根） → 表情卡（只参考根）
                        → 服装卡 LOOK-B（只参考根）
                        → 状态卡 受伤（只参考根）
❌ 错误：P01 → 表情卡 → 服装卡参考表情卡 → 状态卡参考服装卡
```

连锁的后果是误差沿链路累积：根图 5% 的偏差经三次派生变 20%，到第 8 集已经不是同一个人。单根结构下，**任何一张出坏了，单独重出这一张就行，不会连锁**。

### 4 冻结的三样东西

| 冻结项 | 是什么 | 变了会怎样 |
|---|---|---|
| **锚点文件哈希**（sha256） | 根图本体 | 全部派生图标记「过期」 |
| **画风快照** | 画风预设整份快照进资产 | 换画风时连根图一起过期 |
| **文字描述指纹** | 人物描述文本的指纹 | 改描述 → 派生图过期 |

**过期只标记、不删除**，旧版本全部保留（`front-full.v1.png` / `v2` 并排存在，重出不覆盖）。每一代图的文件名带版本号与「参考了哪张图」的元数据，图被单独拷走也查得到来历。

### 5 模型不锁定

一致性来自「同一张根图」，不来自「同一个模型」。实测 Qwen 锚点 + GPT 派生、GPT 锚点 + Qwen 派生都衔接得上。主图与派生图可以用不同模型，同组混用时在交付说明里提醒一句即可。

### 6 根图必须人工确认

根图是全组的根，它不对后面全白出。**根图没确认，派生图不出**。配置为自动放行时，报告里必须标注「未经人工确认」。

## REF 槽位语法

分镜里每挂一张参考图，就是开一个**槽位**。槽位不是「把图丢进去」，而是**向模型声明这张图管什么、不管什么**。三段式强制：

```
REF-<槽位序号>（顺序：<n>）· <项目相对路径>《<中文名称>》
（用途：<用途枚举>；控制：<范围>；不得控制：<范围>）
```

### 1 用途（只能取九项之一）

`身份` / `造型状态` / `地理` / `构图` / `尺度` / `效果` / `起始帧` / `结束帧` / `风格`

- 一图承担两件事：`用途` 写主项，副项写进「控制」——`用途：起始帧；控制：起始构图、本集造型`。
- 一镜最多一张 `起始帧` 和一张 `结束帧`，**有 `结束帧` 必须同时有 `起始帧`**。
- 同一路径只能占一个槽位。

### 2 控制 / 不得控制

- 「控制」写**这一格承担得起的范围**：手背特写不写「本集造型」，不因角色仍在场就顺延上一镜的绑定。
- 「不得控制」写**这一槽位不许溢出到的范围**：构图槽不许带造型，身份槽不许带姿势。

### 3 完整示例（同一场三镜）

```
REF-1（顺序：1）· assets/S01-母版.png《婚纱店母版》
（用途：地理；控制：空间结构、门窗方位、橱窗位置；不得控制：机位、人物、光比）

REF-2（顺序：2）· assets/P01-三视图.png《许念·三视图》
（用途：身份；控制：脸型、发型、身高比例；不得控制：本镜服装、姿势、表情、背景）

REF-3（顺序：3）· assets/P01-LOOK-B.png《许念·今生通勤装》
（用途：造型状态；控制：本集服装、配饰；不得控制：脸、妆容、体型）

REF-4（顺序：4）· assets/D01-四格.png《婚戒》
（用途：效果；控制：戒圈结构、内壁刻字样式；不得控制：持物手势、位置）

REF-5（顺序：5）· shots/SHOT-031-start.png《SHOT-031 起始帧》
（用途：起始帧；控制：起始构图、人物姿态、道具状态；不得控制：本镜动作过程、结尾构图）
```

### 4 槽位超限的取舍顺序

目标模型的参考槽位有上限时（Seedance 2.0 图 ≤9；2.5 全能参考 ≤30 图），按**失去代价从高到低**保留：

```
起始帧 → 说话或主要动作人物 → 必认道具 → 地点 → 其余入画人物 → 定调图
```

放弃的槽位写明，并把必要事实（造型、光向、道具状态）**补写进关键帧正文**，不留空。

### 5 缺图时的写法

- 真实可读图片用 `REF-...`；创作者自己挂的图用 `PLAN-...`（路径位写 `IMG-...` 或 `SHOT-...` 条目 ID）。两者可混用，按「顺序」连续编号。
- 本镜尚无起始帧文件：`PLAN-SHOT-START（顺序：1）· SHOT-031《本镜冻结关键帧》（用途：起始帧；控制：起始构图；不得控制：动作过程）`——本镜照常就绪，不等图。
- 只有创作者明确要求先等图，才写「无（待补参考图：起始帧、地点）」；只有创作者明确选择文生视频，才写「无（创作者已明确选择文生视频）」。

### 6 画面内的视觉依据（与 REF 并列的第二条链）

关键帧正文之外，另写一条**纯文字**依据链，指向《视觉设定》条目：

```
视觉依据：《视觉设定.md》·人物「许念」（控制：脸型与发型）；造型「今生通勤装」（控制：本集服装）；地点「婚纱店」（控制：空间结构）
```

- 必写，逐项引用条目名，名称必须与设定文件标题逐字一致；确无条目写「视觉依据：无」。
- 正文点名了某条目但该人/物**本镜不在画面里**时，末尾追加 `；画外：人物「裁判长」`——用来解释画外音的来源，不代替必要动作的镜头落实。

## SHOT 分镜字段并集

一镜一节的固定骨架。**字段全部为必填**，无内容时写「—」或「无」，**不得整行删掉**（删行 = 下游无来源，且无告警）。

### 1 字段逐条说明

| 字段 | 写什么 | 判据 / 常见错 |
|---|---|---|
| **镜号** | `SHOT-031`，全集连续编号，跨集不重号 | 拆镜保号、并镜留号；改职责才换号。一个镜头拆成 a/b 两条时算一镜，时长相加 |
| **职责** | 这场戏为什么有这一镜：推进了什么 / 观众新知道了什么 | 切镜必须带来信息、权力、情绪、空间、节奏五变化之一；写不出职责 = 该镜不存在 |
| **来源场次** | 以剧本真实存在的场次 ID 开头，可跟一句引文：`场3 / 「这婚，我不结了」` | 剧本每个场景都要有镜头承载；跨场用「、」连接；确需省略在正文开头写「未拍场次：场 N（理由：…）」 |
| **时长** | 整数秒（`5s`）；同一多镜容器内的短镜可写半秒，容器总和须成整数 | 不按字数折算镜长；超过模型单条上限的镜拆 a/b |
| **景别** | 远 / 全 / 中全 / 中 / 中近 / 近 / 特 | 相邻三镜不得同景别；景别跳跃要服务情绪落差 |
| **机位与焦段** | 角度 × 高度 + 焦段：`侧45°+微仰，50mm` | 侧 45° 为默认；常规平视 ≤30%；荷兰角每集 ≤1；3D/仿真人禁「特写×平视正面」 |
| **运镜** | 推 / 拉 / 摇 / 移 / 跟 / 升降 / 手持（三级烈度）/ 固定 | **固定也要写理由**（「固定，让观众看清它抖的手」）；一镜一条简单运镜，禁一镜多转折 |
| **起点** | 进镜瞬间：人物姿态、双手、持物、道具状态 | 起点必须是上一镜终点可承接的状态，不靠镜外瞬移 |
| **唯一动作** | 这一镜只有**一个**主要动作，写清谁做、做到哪 | 动作超载就删、并、拆镜；峰值重复冲击除外 |
| **终点** | 出镜瞬间：姿态、双手、持物、道具状态 | 终点要能成为下一镜可信起点；交接/换手/放置/取回必须写清接触者、接触方式、物件落点 |
| **声音与台词估时** | 台词原文 + 字数 ÷ 4 字/秒 + 可用窗口核算 | 可用窗口 = 镜长 − 开口前等待 − 不能并行的动作 − 轮流发声 − 末尾反应；超载先删无功能动作，再回分镜拆镜，**严禁在视频层删改台词或催快语速** |
| **站位朝向** | 画左 / 画右 / 前景 / 背景；面向哪边、依托什么（桌、门、窗） | 同场先写「场景站位」总锚点（固定锚点 + 各人相对位置 + 轴线 + 摄影机工作侧），镜内只写位移增量与依托物 |
| **视线落点** | 目光落在谁的脸上 / 哪个物件 / 画外哪个方位 | **每镜只锁 1 个视线落点**；单人镜视线方向不点名画外角色名（点名谁，模型就把谁塞进画框） |
| **首帧参考** | 本镜起始帧的 REF / PLAN 槽位，以及挂哪张身份、造型、地理图 | 见 §七 REF 语法；起始帧不等于参考图，首帧必须另绘 |
| **段缝衔接方式** | 与上一镜/上一段怎么接：动作重合 / 视线匹配 / 景别跳切 / 运镜接续 / 声音桥 / 硬切 | 段内衔接查五维：轴线、视线、动作 60–80% 重合、道具状态、景别不连续三镜同景别 |

**另外两条分镜层专用字段**（只活在分镜稿，投喂前剥离）：

- **状态**：`{进镜} → {出镜}`，专拦姿态回退（上一镜已起身、下一镜按字面渲染成坐姿）与道具瞬移（换手无递接、桌上手里各一个）。
- **重音**：每句台词标一个语义与情绪最重的字/词，供特写挂句、表情峰值对齐、配音重读三处取用。

| **唯一动作** | 许念抬手把婚纱裙摆从镜台边拎起一寸，又放下 | 许念视线从镜中移到镜外的周然 | 许念说完这句话，把话尾压平 | 周然的笑容从嘴角开始凝固，手机缓缓下移两寸 |
| **终点** | 裙摆放回镜台边缘，许念双手仍在身侧 | 许念目光落在画右的周然脸上 | 许念下颌回到水平，唇闭合 | 手机降到腰际，屏幕仍亮；笑容完全消失 |
| **声音与台词估时** | 无台词；店内轻音乐，远处试纱声。0 台词 / 4s | 无台词；只有布料摩擦声。0 台词 / 3s | 「这婚，我不结了」7 字 ÷ 4 = 1.75s；开口前静默 1.2s + 末尾反应 1.5s ≈ 4.45s，5s 内可容 | 无台词；轻音乐骤停。0 台词 / 4s |
| **站位朝向** | 许念画左、面朝画右；周然画右、面朝画左；两人相对，隔镜台 | 许念居中偏左，面朝镜（背对画右），头部微侧 | 许念画左、面朝画右，二人中景双人同框 | 周然画右，3/4 侧朝画左，背后是橱窗 |
| **视线落点** | 周然 → 手机屏幕；许念 → 镜台边缘 | 许念 → 镜中的自己，再 → 周然的脸 | 许念 → 周然的眼睛 | 周然 → 许念的脸（不落在手机上） |
| **首帧参考** | 起始帧 SHOT-001-start；P01 三视图（身份）、P01-LOOK-A（造型）、S01 母版（地理） | 起始帧 SHOT-002-start；P01 三视图、P01-LOOK-A | 起始帧 SHOT-003-start；P01 三视图、P01-LOOK-A、P02 三视图 | 起始帧 SHOT-004-start；P02 三视图、P02-LOOK-A、D01（婚纱，背景） |
| **段缝衔接方式** | 段首，无前接 | 动作重合：001 末尾裙摆放下的手 → 002 开头同一只手的位置；景别从中近起 | 视线匹配：002 末尾许念目光落到周然 → 003 顺这条视线接正反打 | 景别跳切：中 → 近，反打不越轴（摄影机仍在镜台一侧） |

## 关键帧提示词规则

关键帧是视频生成的起点。**冻结起点，删除终点才有的信息**——这是防「模型抢跑」的唯一手段。

### 1 只写这一瞬间能看见的

```
✅ 「许念站在镜台左侧，双手垂在身侧，下颌微抬，目光落在镜中的自己身上。
    镜台右侧，周然右手举着手机，屏幕亮着，嘴角还挂着笑。」
❌ 「许念拎起裙摆又放下，转身对周然说这婚她不结了。」
   ↑ 这是三秒内发生的事，不是一瞬间；模型会把它压进第一帧，动作过程就没了
```

三条判据：

- 正文里每个词都能画出来吗？（「悲伤地」画不出，「下唇内收、眼睛眨得慢」画得出）
- 这句话描述的是**状态**还是**过程**？只留状态。
- 有没有终点才出现的文字、动作、姿态、道具状态被写进了起始帧？全部删掉。

### 2 删除清单（终点才有的，一律不写进起始帧）

| 类型 | 例子 | 为什么不写 |
|---|---|---|
| **动作过程** | 「正在推门」「正要开口」 | 起始帧只剩一半动作，视频里动作会僵死或重复 |
| **位移结果** | 「已经走到窗边」 | 写进起始帧 = 这一秒就到了，中间的路没了 |
| **终点姿态** | 「说完后垂下头」 | 抢跑，视频第一帧就是结尾 |
| **战损/污渍结果** | 「衣服上沾了血」 | 若本镜是受伤镜，起始帧必须干净，脏污由视频过程产生 |
| **文件/手机屏内容** | 「合同上写着赔偿三千万」 | 文字后期做；写进关键帧会生成乱码伪文字 |
| **可拆卸道具的离手状态** | 「戒指已摘下放在桌上」 | 起点应是「戒指戴在手上，手指已搭上戒圈」 |
| **他人反应** | 「周然惊恐」 | 若本镜是许念的镜，周然的反应属下一个镜的起点，写进来会抢戏 |

### 3 与「终点帧」成对

需要锁收尾构图时，另写一条**收尾关键帧**，规则对称：**删除起点才有、终点已消失的状态**（案上手印、手里的空杯、正在落下的布）。取舍原则：**起始帧是必需，收尾帧是可选**；有收尾帧必须有起始帧，且两帧的人物、机位、光向、轴线必须同源，否则视频会「穿越」。

### 4 正文写法与分离

- 关键帧正文使用**与画风句一致的单一句式**：同集每条正文用同一句画风（写实不混用「漫剧」「插画」）；同场景用同一句光与色温。
- 关键帧正文**只装画面语言**：不写编号（图 N）、不写自检项、不写延续备注——流程说明单独成段放在文末，与画面描述物理隔离。
- 画外音、内心独白不进关键帧正文；需要时在「声音」栏注明并写明该角色**闭口**（否则模型会让他张嘴）。
- 《视觉设定》里的连续性锁（服装锁、道具颜色锁）在生效镜头上**原样写进关键帧正文**，此帧照旧生效。

## 故事板图

故事板图 = **带人物 + 带动作相位 + 带镜头信息**的多面板图，**每段一张**，是给视频生成的视觉依据。它不是九宫格场景图（九宫格是纯场景无人），也不是推演用的剧情分镜格（那是一段连续叙事的四个瞬间）。三者互不替代。

### 1 动作相位七态（拆格的唯一依据）

| 相位 | 这一格必须出现的内容 |
|---|---|
| **1 起始** | 动作发力前的常态；上一段的出口状态 |
| **2 过程** | 力开始传递，身体重心/肢体出发 |
| **3 接触** | 两个物体或两个人真正触碰的那一下（打戏必出） |
| **4 顶点** | 冲击最大、形变最夸张的一格（峰值） |
| **5 结果** | 受力方落位、物件变形、尘土落定 |
| **6 反应** | 旁观者或被打者的表情与身体回应 |
| **7 出口** | 本段结束时停留的画面 = 下一段的入口 |

每格必带五项：**面板 ID / 动作相位 / 镜头信息（景别·机位·焦段·运镜）/ 站位+视线 / 资产引用（P/D/S 编号）**。缺项 = 该格不能落进投喂镜行。

### 2 格数 = 镜数

**一段几镜就几格，不设固定格数。** 4 / 6 / 9 / 12 格都正常：

| 格数 | 版式 | 常见段型 |
|---|---|---|
| 4 | 2×2 | 文戏短段（起势 / 变化 / 反应 / 出口） |
| 6 | 2×3 | 文戏长段、通用打戏 |
| 8 | 2×4 | 多人调度段 |
| 9 | 3×3 | 玄幻大招 / 群战重场、九人群戏 |
| 12 | 3×4 | 重场戏全集段落 |

**禁止机械凑九宫格**：把「文戏 4 格」「打戏 6 格」当**下限**去砍镜，会让故事板与投喂稿对不上（实测事故：6 镜的文戏段被压成 4 格，丢了两镜）。**格数永远服从镜数**；确需合并两镜时写 `〔镜K+M〕` 并在段首写理由。

### 3 图面零文字（干净版）

- 必出 **CLEAN_GRID 干净版**：无任何文字——无格号、无对白框、无箭头、无技术标签、无水印、无边框文字。
- 可选出 **TECHNICAL_ANNOTATED 标注版**：仅供人工沟通与自查，**不进投喂、不入册、不占参考图槽**。
- 文字进图走「图模分工」：模型只出无文字画面，格号/参数/台词由排版叠加，零伪文字风险。

### 4 三条禁令

1. **面板边界 ≠ 剪辑点**：面板只表示动作相位，切不切镜由分镜的镜头策略决定；不得用「多画一格」暗示未获授权的反打或插入。
2. **不得新造内容**：故事板是执行稿不是再创作，每格必须能回溯到分镜与导演稿；出现矛盾 = 废图重出。
3. **一格都不许漏**：逐格落进投喂镜行；漏格 = 该动作相位在成片里不存在。

### 5 出口帧六项（段缝的画面锁）

出口帧 = 下一段的入口帧，必须写全六项：**人物 / 手位 / 道具状态 / 光影 / 轴线 / 未完成动作**。分镜的「段缝衔接方式」写「出口帧同源·SHOT-0NN 末帧」，不写文字腿。

### 6 出图提示词骨架

```
<段号> 故事板 · 全图共 <N> 格
风格：<与该集关键帧同一句画风句>；<同一句光与色温>
版式：<N> 格等大，<版式如 2×2 / 2×3 / 3×3> 网格，格间留细白边，画面内无任何文字
格1（起始）：<人物>，<景别机位焦段>，<站位朝向与视线>，<姿态与持物>
格2（过程）：……
…
格N（出口）：<六项写全>
负向词：文字，格号，对白框，箭头，水印，多余人物，多余的手指，五官扭曲，第五格以外多余面板
```

### 7 交付清单必列（禁静默跳过）

```
故事板图：段1 ✅ 4格(2×2) / 段2 ✅ 6格(2×3) / 段3 ⛔豁免（单镜过场段，理由：__）
```

不列清单又没出、或只写「略 / 同上 / 按需」= 该阶段未完成。用户点名要时一律必出，不适用豁免。
