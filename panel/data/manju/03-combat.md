## 打戏分档判据 —— 什么戏走 R1 / R2 / R3，怎么判

打戏不是一种东西。对所有题材强制同一套高燃套路，结果是写实格斗被写成放烟花、玄幻大战被写成两个人在泥地里推搡。所以动笔前第一步是**定档**——档位决定后面套哪一套规则、开不开特效、要不要开局硬撞、收尾能不能定格。

### 一、先定档再动笔（硬纪律）

> ⚠️ **总纲铁律（2026-09-02 实测二次翻车后固化）**：AI 视频没有"静止表演"能力。任何"对峙 2 秒 / 蓄势待发 / 留白 / 悬停 / 站立 / 特写定格"类静止段，模型都会渲染成角色呆立几秒、节奏拖沓。**一切情绪与蓄力必须在运动中完成**：边打边蓄、上升途中蓄、后撤中蓄；神态挂载在动作瞬间（甩剑转身时冷笑），不单独成段。唯一允许的"定格"是**命中瞬间 1~2 帧微停顿（Hit-Stop）**，其余静止段默认禁用。

三条定档纪律：

1. **未定档不得动笔写打戏**；
2. 一集同一场战斗原则上**单档**，混档必须写明切换点（第几秒、什么事件触发）；
3. **R3 档切换法术语言**——法宝媒介 + 五行术法 + 术法攻防 + 能量具象化 + 对军清场，**不硬套武侠物理打斗**；**R1 档不套用高燃套路**（不强制 0.5 秒硬撞、不强制气爆、不强制定格）。

### 二、三档总表

| 档位 | 适用题材 | 开局硬撞 | 近景机枪对招 | 气爆/特效 | 终结定格 |
|---|---|---|---|---|---|
| **R1 写实克制** | 写实格斗、悬疑暗杀、追逐、喜剧打斗、儿童向 | 不强制，1.5s 内发生接触即可 | 可选 | 不强制，以真实受力反馈为主 | 允许收势/悬念收尾 |
| **R2 商业高燃（默认）** | 多数短剧/漫剧打戏（武侠、古装、奇幻近战） | 必选 0.5s 硬撞 | 必选 1 段 | 必选 | 必选高潮定格 |
| **R3 玄幻大招** | 仙侠/二次元/特效向、剑阵法相、对军清场 | 必选 | 必选 | 拉满 | 必选最高燃定格 |

**定档后的规则库路由**：R1 → 写实档的格斗规则库（动力链、防守三态、物理受击、多敌轮转）；R2 → 本引擎（招式库 + 八句母版 + 冲击帧 + 激烈度护栏）；R3 → 玄幻档规则库（法术系统、剑阵法相、史诗战场协议）。冲突时以对应专档为准。

### 三、判据：怎么落到具体一场戏

判档看四个变量，按顺序问，答第一个"是"就停：

1. **有没有超自然能力在打？**（灵力/法术/法相/巨兽/剑阵 → 是则基本锁定 R3）
2. **身体有没有内力/轻功/刀气这类"半写实"强度？**（能飞檐走壁、能一掌震碎石墙，但没有光效法术 → R2）
3. **打得是不是"人"？**（真人写实的拳脚格斗、暗杀、追车、枪战 → R1）
4. **戏的功能是什么？**（开场立威/爽点兑现/大招收官 → 往上调一档；情绪铺垫/悲壮/喜剧 → 往下调一档）

**题材速判表**：

| 戏型 | 推荐档 | 关键理由 |
|---|---|---|
| 都市搏击、擂台、街头械斗 | R1 | 物理受力是唯一视觉证据 |
| 悬疑暗杀、潜行、狙击 | R1 | 中远距交火，允许一方静止 |
| 追车、跑酷逃脱 | R1 | 位移是主戏，接触很少 |
| 轻松喜剧打斗、儿童向 | R1 | 夸张但不血腥，靠节奏与反差 |
| 古装武侠、刀剑对决、江湖仇杀 | R2 | 有刀气与轻功，但仍是"人打人" |
| 修仙者近身对决（未放大招） | R2 | 招式为骨，光效为皮 |
| 术法对轰、剑阵、法相、万剑归宗 | R3 | 战斗语言是"术"不是"招" |
| 单人 vs 满屏兽潮/军阵 | R3 | 群战清场逻辑，与双人对拆完全不同 |
| 都市修仙（日常写实 + 能力爆发） | R1↔R3 双态 | 按爆发信号切换，见本节第五节 |

### 四、15 秒打戏完播潜力评分（R2/R3 档自检）

$$\text{完播潜力评分} = 0.20 \times \text{开局吸引力} + 0.30 \times \text{节奏呼吸} + 0.25 \times \text{运镜丰富度} + 0.25 \times \text{情绪拐点}$$

这是创作者自检用的**加权启发式**，不是平台完播率预测模型。R1 档可选择性满足。

| 维度 | 权重 | 执行硬指标（R2/R3 档） |
|---|---|---|
| **开局吸引力** | 20% | **0~1.5 秒内必须发生攻防接触**；R2/R3 档 0.5 秒内出现两种对立招式的正面硬撞 + 命中瞬间微停顿。第一帧建议双人同框中近景，避免远景风景慢热铺垫。 |
| **节奏呼吸感** | 30% | 快慢交替，同节奏连续 ≤5 秒。极速密集连打之间用**命中瞬间 1~2 帧微停顿**或瞬间加速制造反差，**禁用慢镜/升格**（2026-09-02 实测破坏节奏）。 |
| **运镜丰富度** | 25% | **同运镜 ≤2 秒，同景别 ≤3 秒**。重磅终结采用三段式运镜（低仰蓄力 → 俯冲跟随 → 碰撞定格）。 |
| **情绪拐点** | 25% | 在 8~12 秒区间必须出现一次局势逆转、破防爆发或破绽抓取。 |
| **以高潮收尾** | 核心 | R2/R3：禁止 0.5 秒平缓收尾帧（收腿落地/发丝飘落/气焰消散）；最后一帧停在终结技命中、重创失衡、冲击波炸裂、碎石掀飞或倒地嵌墙的最高潮定格。R1：允许克制收势或悬念收尾。 |

**开局硬撞的两个变体**（2026-09-04 吸收）：

- **零帧瞬移起手**：第一帧即瞬移至对手面门前出招（残影/空间撕裂作瞬移痕迹），省略冲刺过程；瞬移必须有视觉痕迹（残影/黑色空间裂隙/空气扭曲），禁无来由跳切；
- **弹射迎击对冲**：守方不原地挨打——弹射起跳/蹬地迎击，与攻方在近身位或空中对冲碰撞。仍守"0.5 秒内硬撞 + 命中微停顿"。

### 五、混合档（都市修仙双态切换）

纯仙侠全程修仙版、纯都市全程写实版；只有"日常写实 + 修仙爆发频繁切换"的题材才走双态。

**写实 → 能力爆发态（出现任一即切）**：① 周身灵力雾气升腾/真气外露；② 眼睛变色/瞳孔发光/眉心印记亮起；③ 武器或饰品发光、表面浮现符文；④ 周围物体悬浮/碎石震起/空气扭曲；⑤ 脚下或空中展开法阵；⑥ 台词暗示（"认真了""不再留手""解封"）。

**回落信号**：灵力雾气消散/真气收回；眼睛恢复正常/符文熄灭；法阵碎裂成光点；角色力竭/收功。

**过渡必须有因果（1~2 帧，禁硬切）**：灵力雾气从身体向外扩散，所过之处画面色彩微升饱和度/增强对比度；法阵从一个光点扩成完整阵法、光照亮环境；眼睛发光特写 → 拉中景时角色已被气场包围。回落时反过来：雾气回流身体、最后一丝光从指尖收回、法阵碎成光粒上飘、画面恢复日常色调（信号与降级细则见「打戏分档判据」第五节）。

**配额**：日常写实态占 60%~70%，能力爆发态占 30%~40%；每次爆发 ≤20~30 秒；两次爆发之间至少间隔 1~2 分钟的日常戏；季终可连爆，但必须用旁观者反应镜与角色力竭回落做呼吸点。

**能力受限角色（幼童身体/重伤/封印中/灵力耗尽）的特效降级**：法阵缩到巴掌到脸盆大、可能只有半个；法术缩到 1~5 米甚至一束光；稳定性差（闪烁/忽明忽暗/中途熄灭/颜色不对）；气场只剩半径 0.5~1 米时有时无；命中效果缩水（炸个坑/吹阵风）；只能持续数秒到十几秒然后力竭。写法写出不稳定感：闪烁、滋滋声、施法者憋红脸手抖咬嘴唇。**偶尔靠谱一次**：在情感/危机顶点短暂爆出完整规格 1~2 秒，随即力竭——这就是燃点。**召唤物不降级**：被召唤的帮手若自身战力正常，其特效按正常尺寸。

**旁观者反应镜五型**（神仙打架 + 凡人懵逼的反差）：震惊型（瞳孔骤缩→下巴微张→后退半步→揉眼）｜吐槽型（面无表情→扶额→翻白眼）｜难以置信型（眨眼→再眨眼→掐自己）｜恐惧型（脸色发白→后退→躲到障碍物后只露半张脸）｜崇拜型（眼睛变星星→张嘴→双手握拳）。规则：走日常写实态画质、无特效；在法术爆发后 0.5~1 秒插入、时长 ≤1 秒；**禁止插在连击段/交锋段中间打断节奏**，只能在一击结束后的间隙插；35~85mm 中近景/特写、极浅景深奶油散景；旁观者态度要从"不信→震惊→怀疑→接受→崇拜"渐进，不能一集全信。

## R1 真人格斗 —— 11 环动力链、防守三态、受击物理、机位与景别要点

R1 不是"没有规则的打戏"，它是**把规则全部压在物理上**的一段。特效不是没有，而是没有——力量感只能靠身体、靠重量、靠镜头被撞。

### 一、11 环动力链（发力必须走完整条链）

一次有效的打击不是"手伸出去"，是力量从地面一路传导到接触点。R1 的每次攻击，脑内按 11 环过一遍，落字时把可看见的环节写出来：

| # | 环节 | 画面证据 |
|---|---|---|
| 1 | **蹬地** | 后脚掌碾地、鞋底摩擦、地面细尘被蹬开 |
| 2 | **转胯** | 髋部转动带动躯干，重心从后脚压向前脚 |
| 3 | **腰** | 腰椎拧转、腹部收紧 |
| 4 | **肩** | 肩胛前送、出拳侧肩膀明显前探 |
| 5 | **肘** | 肘部开合决定直线/弧线，肘尖朝向即发力方向 |
| 6 | **腕** | 腕部锁紧成一条直线，拳面朝接触点 |
| 7 | **接触点** | 具体的身体部位落点（见本节受击部分） |
| 8 | **受力传导** | 力穿入对方身体，从躯干传到脚 |
| 9 | **对方重心破坏** | 后脚跟离地/侧移/单膝沉 |
| 10 | **反作用力回传** | 自己的手臂被弹回、脚下后挫半步 |
| 11 | **复位** | 收拳回护、重新建立架势（不是摆 pose，是在动中找平衡） |

**硬要求**：

- **零滑步、零漂浮**——脚永远有接触点，位移必须有蹬踏与地面反馈；
- 发力链断了就等于招是"贴上去"的，AI 会画成两个人手碰手；
- 每个动作后必须给**反作用力回执**：打人的人自己也会被顶回去半寸，这一寸是力量感的来源；
- 短打（寸劲、贴身肘膝）也走完整条链，只是前 5 环在极短时间内完成、画面体现为"腰胯一沉"。

### 二、防守三态

R1 的攻防必须**有来有回**（R2 也继承这条），守卫方永远要让观众看见它做了三件事之一：

| 态 | 做法 | 关键视觉 |
|---|---|---|
| **① 格挡（挡）** | 用手臂/兵器硬接，接住后身体被压退 | 手臂震颤、鞋底在地面擦出印、接住后面部肌肉一紧 |
| **② 卸力（化）** | 侧步、转体、拨开，把力引向别处 | 攻击从身侧擦过、衣袖被带走、对方因扑空前倾 |
| **③ 闪避（让）** | 后撤、下潜、侧滑，靠位移躲开 | 攻击击空必须**打爆环境**（击空打进墙体/地面/器物），不允许打空气 |

**守方三纪律**：不允许"脸不动、身体不动、只有血冒出来"；受击前要有**前摇反应的微动作**（眼神收紧、肩部微缩）；**闪避幅度必须写大**——不是"微微侧头"，而是重心整个挪出攻击轴线，否则 AI 会画成两人贴着互相点头。

**击空必打爆环境**：一次闪避成功，画面要给出"打在哪了"的答案（墙皮炸开、栏杆断裂、地面出现浅坑），这是 AI 唯一能理解"这一下打空了"的信号。

### 三、受击物理（按部位写连锁，禁止整体平移）

**受击连锁**（禁止只写"被打飞"、禁止整体平移）：

| 命中部位 | 反应链 |
|---|---|
| **胸口** | 胸腔凹陷 → 肩后缩 → 头后仰 → 腰反弓 → 重心后移 → 脚后退 |
| **腹部** | 腹肌收缩 → 身体前屈 → 头低下 → 膝弯曲 → 单膝跪 |
| **头部** | 颈部偏转 → 头部甩动 → 视线模糊 → 身体失衡 → 脚步踉跄 |
| **腿部** | 膝盖弯曲 → 重心下降 → 身体侧倾 → 手扶地/单膝跪 |

近身拳脚命中部位锁死在：**太阳穴 / 下巴 / 喉咙 / 肋骨 / 腹部 / 锁骨 / 胫骨**。

**四列反馈表**（每个等级四项缺一不可）：

| 等级 | 身体 | 武器 | 环境 | 镜头 |
|---|---|---|---|---|
| 轻击 | 微颤/侧头 | 回弹震颤 | 小碎片/脚下沙环 | 微震（沿攻击方向） |
| 重击 | 弓身/后仰/退数步 | 大幅回弹/脱手风险 | 冲击环 + 地面龟裂 + 尘浪 | 短促震动 + 弹性后弹 + 碎片擦镜 |
| 终结 | 旋转飞出/撞穿建筑/双脚离地 | 脱手飞出/插入地面 | 大范围崩塌/建筑整面塌 | 后坐力机位撞退 + 剧烈震动 + 5° 旋转 + 瞬态失焦 + 定格锁机位 |

**震屏必须带方向**：横斩左右震、纵劈上下震、终结技全向 +5° 旋转分量；禁无方向随机抖动。

**肉陷阻滞帧**：接触瞬间 0.05 秒的"陷进去再弹出来"，肉搏/体修题材启用，能量对轰不强制。

**打击感四档（镜头侧口径）**：

- **轻击级**：受击部位凹陷 + 面部肌肉拉丝 + 头部猛然后仰 + 汗珠弧形飞溅；环境拳风带起尘土、衣摆被吹直；镜头微推后 + 震屏，0.03 秒轻微过曝提亮；
- **重击级**：胸口凹陷 + 背弓成 C 型 + 受击点爆裂向外扩散；气浪吹飞碎石 5~8 米；镜头一道白光从碰撞点炸开覆盖 50%~70% 画面 + 径向形变 + 速度线拉满 + 机位被推后 + 震屏 0.06 秒；
- **轰飞级**：身体水平飞出、四肢随惯性摆动；砸地产坑 + 烟尘柱；低角度跟拍飞退、动态模糊拉满；
- **终结级**：蓄力特写 → 轰出中景低角度 → 爆炸三层演进（白橙光团 → 橙红火焰 → 灰黑烟尘）→ 收束背影；镜头纯黑一瞬 → 爆白 + 鱼眼畸变 + Bloom 峰值 → 猛推后猛拉。

### 四、Hit-Stop 三级（R1 也要，但只给接触瞬间）

| 等级 | 顿帧时长 | 升格 | 缩放冲击 | 画面表现 |
|---|---|---|---|---|
| 轻击 | 0.1s | 48fps | 微缩放 | 受击部位微形变，机位微微一挫 |
| 重击 | 0.15~0.2s | 120fps | 缩放冲击 | 放射冲击 + 中心负片 + 受力猛沉回弹 |
| 大招 | 0.25s 以上 | 240fps | 缩放 + 定格锁机位 | 全屏负片闪白 + 机位纹丝不动 |

**帧率快门联动**：基础 24/30fps、1/48s 快门；命中升格 48~120fps、1/2000s 快门（冻结碎屑、肌肉拉丝）持续 0.2~0.3s 立刻恢复；大招核心 240fps、1/20000s；爆发恢复切 1/15s 慢快门拉出运动拖影。

**三条禁令**：顿帧只给命中瞬间，过程/蓄力/位移禁停顿；轻/重/大招三级必须分开写，禁止所有命中套同一档；连续两个慢镜、单个慢镜超 0.5 秒都违规。每场打戏慢放**最多 2 次**，只用于重击/终结/关键格挡；慢放内容必须写清"慢放了什么"（接触时皮肤凹陷的 0.08 秒），不是"慢动作"三个字。

**蓄力四档**（禁超 2 秒，超了拆成独立蓄力镜）：轻击 0.2s｜中击 0.3s｜重击 0.5s｜终极 1s。交锋段的蓄力只能挂在高速位移里（边冲边蓄、借格挡反弹蓄），≤0.25 秒，蓄力期画面不许静止。

### 五、机位与景别要点

**五要素强制**：每次写镜头都要给出 [景别] · [拍摄视角 + 具体角度] · [运镜方式] · [跟随目标]——"手持/固定/跟拍"不算描述，要写成可执行句（摄影机在哪个空间位置、对准什么、运到哪里）。

- **中景及以上（看到双人全身或大半身）严禁 90° 侧面正拍**——会产生横版格斗游戏的平面廉价感，必须 30°~60° 斜角，靠前后遮挡与纵深制造对决压迫；只有近景/特写（胸以上、手部细节）才允许 90° 侧拍。
- **景别与动作幅度匹配**：大幅动作（腾空下劈、大步位移、轻功折返）必须全景/中景，展现舒展身形与位移；小幅动作（寸劲短打、腕剑翻转、贴身截击）必须近景/特写，放大击打密度。
- **短焦贴脸没有重量**：力量感来自"看见重心"，所以**全身档必须占够**——每 2 镜至少 1 镜全身入画（中全景/中景/全景）；贴脸档（特写/近景/中近景）连续不得超过 2 镜，第三镜必须切回全身档。
- **机位也会被打**：命中瞬间机位按攻击方向受力——横斩左右震，纵劈上下震，终结被冲击波推后飞；机位可以滞后（人飞走了镜头晚 0.2~0.3 秒才跟上），可以甩出画框再补抓。
- **景别机位要交替**：WS/EWS/FS/MS/CU/ECU 六档 + 正/侧/背/俯/仰/环绕六种机位，每 3~5 镜必切换；允许成对切换（MS→CU→MS），但组与组之间必须换档。

**运镜选择流程**：① 判断这一动为什么服务（情绪 or 动作结果）→ ② 判断节奏档位（动作段默认高密度）→ ③ 从行为锁表选 1~2 个核心组合 → ④ 先写摄影机行为锁（类型/位置/高度/方向/速度/起止 + 禁止项）→ ⑤ 段内组合数：4~8 秒 ≤1 个、10~15 秒 ≤2~3 个 → ⑥ 组合编号不进最终 prompt。

**常用行为锁（可直接落字）**：

| 场景 | 机位写法 | 禁止 |
|---|---|---|
| 对峙/审判 | 固定在两人正前方眼平中景，主体保持中央，不推拉不摇移，只让人物动作改变画面 | 随机漂移、无动机变焦 |
| 追击/压迫 | 角色右侧约 1 米手持侧跟，速度与脚步同步，转弯短暂甩动后重新稳住 | 突然越轴、跟丢角色 |
| 主体逼近 | 正前方胸口高度倒退跟拍，角色前进一步镜头同步后退 | 速度忽快忽慢、撞到角色脸上 |
| 冲击/揭示 | 主体冲向镜头，接近瞬间摄影机快速后撤到广角全景，露出身后阻挡物 | 后撤后空间结构改变 |
| 动作高潮 | 高潮瞬间向画右快速甩镜，运动模糊遮满画面后切到同方向新角度 | 甩后空间方向反掉 |
| 情绪压迫 | 从中景缓慢推到眼睛特写，速度逐渐变慢，到眼神处停住 | 空泛"电影感慢推" |

**R1 的运镜气质**：手持微动（克制焦虑、私密不安）、手持跟拍（追逐、慌乱）、稳定器跟拍（穿场）、长焦压缩（压迫距离）。**避重禁用**：环绕炫技、360° 旋转、无人机航拍大远景（R1 的规模来自肉体与空间，不来自天地）。

## R2 武侠 —— 八句母版、招式库、冲击帧分级、负面词库

R2 是默认档：有内力、有刀气、有轻功，但底子仍是"人在打人"。所以 R2 的两条腿——**招式是骨、句法是皮**。招式库管"打什么招"，八句母版管"怎么把这招写成画面"。

### 一、八句母版（唯一输出句式标准）

🔴 每一句最终输出必须是以下八类自然句之一或其咬合。**禁止关键词袋、禁止竖线串、禁止"内容｜内容｜"、禁止字段罗列**；字段只准存在于脑内。

| # | 母版 | 语序公式 | 用途 |
|---|---|---|---|
| 1 | **宏观揭示句** | 机位焦段景别 → 画框分区（天空/地面/上中下层各占几成）→ 大环境 → 特效主体（材质 + 规模四件套）→ 极小人物位置 → 镜头运动反应 | 证规模。开场铺规模、大招成型全景、EWS |
| 2 | **动作-特效释放句** | 人物发力链动作 → 特效从肢体/武器长出（材质 + 形态）→ 沿明确轴线飞行 → 命中目标 → 三层反馈 → 环境结果 | 证招式与轨迹。每镜核心句 |
| 3 | **打击反馈句** | 接触瞬间 + 顿帧冲击帧 → 受力体形变 → 位移 → 三层粒子 → 环境连锁 → 镜头受力 | 证力量。每次命中必用 |
| 4 | **蓄力压缩句** | 手/眼/刃特写 → 粒子从八方螺旋汇聚 → 材质微观细节 → 临界万物悬停 → 镜头微震蓄压 | 大招前必用；交锋段蓄力必须挂在高速位移里，≤0.25 秒 |
| 5 | **尺度证明句** | 先给参照物/画框锁规模 → 让特效做一个能对比的动作（扫过云层/切开雪雾/吞没建筑） → 再给极小人物位置二次确认 | 证规模。禁只喊"巨大/终结级" |
| 6 | **追尾位移句** | 位移起法（蹬/踏/借力点 + 碎裂反馈）→ 长距离方向跨度 → 拖尾残影 → 原位置被追来的攻击打爆 → 镜头滞后追赶/被甩出画框 | 证速度。瞬移/高速位移专用 |
| 7 | **群体结构句** | 先定义群体组织结构（几路/几层/前部中后部）→ 整体运动方式（鱼群/潮水/星河同相位）→ 个体在结构里分工 → 镜头停在群体外部看整体轮廓 | 群战/万剑/妖潮必用；禁"密密麻麻糊一团" |
| 8 | **收势/延迟揭示句** | 动作收束（入鞘/合扇/咔哒）→ 极短时间冻结 → 裂纹/效果延迟蔓延 → 延迟爆发或粒子逆流回收 → 镜头匀速拉远留动态背影 | 结尾必用；禁双方同框摆 pose |

**出稿前每镜自问（任一答不上，这句是空话，重写）**：

1. 这镜任务是什么？（证规模/证力量/证速度/证招式/证轨迹/证情绪，一镜一主任务）
2. 观众站哪？（机位此刻在哪个空间位置、对准什么、运到哪）
3. 特效什么材质、分几层、占画框多少、对照什么参照物、人物在画框哪个位置？
4. 力从哪起、收到哪三张回执？（命中 → 身体 → 环境 → 镜头）
5. 镜头被什么事件推动？（运镜方向 = 事件方向）
6. 和上镜怎么接、给下镜留什么？（末帧接首帧、隐形剪辑点、钩子）

**词汇回落句**：每个强词（炸裂/吞没/坍缩/翻涌/螺旋/音爆环/犁沟/虫视/暴拉/Whip Pan）必须带 ① 搭配对象 ② 句中位置 ③ 服务的画面，回落到完整句。**脑内可以按字段想，落字一律自然句**——用户硬要求，无例外。

**词汇禁则（水墨/国漫/二次元档优先）**：严禁只写「粒子」「光效」「能量波」「光芒」「烟雾」这类通用概念词——写了就等于把控制权交给模型的默认粒子库。每个特效概念词后必须跟一个具体表现手法（泼墨飞白笔触 / 漫画色块叠加 / 手绘速度线 / 墨线勾勒 / 笔触拖尾）。

**动词禁则**：严禁长时状态动词——「双手横架死封」「对撞定格」「持续相持推刀」「脸贴脸对视」会被模型解析成数秒静止姿态。强制用瞬态爆发动词——「劈中即分」「震退即变招」「侧身滑步避开」「借反弹力暴退三米」「反手挑刺」「中拳滑退」。

**特效强动宾化**：❌「五路立体鱼群剑海如星河倒泻」→ ✅「无数柄寒光飞剑自天穹垂直向下暴雨般俯冲突刺，迎头扎向刀客头顶」；❌「斩出一轮三百米暗红血月巨刃」→ ✅「双手举刀斩出一道横贯断崖的半月形墨黑巨刃，刀气贴地削断沿途成排石柱」。

**连招模板（30 秒三技能递进）**：0~10s 技能 1（割草铺场）→ 10~20s 技能 2（法阵范围压制）→ 20~30s 技能 3（灭世清屏 + 尾帧绝杀定格）；每 10 秒一个毁天灭地大招，大招之间用微技能与位移缝合（技能取消无缝衔接）；段尾用"满屏粒子糊镜/光爆糊屏"转场，末帧接首帧分段生成。

#### 4. 大型法阵 10 种（速查）

攻击型：九霄雷阵（36 道天雷交织）、焚天烈焰阵（火柱汇聚火龙卷）；防御型：玄冰护盾阵（半球冰盾吸收转化寒气）、金刚伏魔阵（圆柱壁垒 + 金刚怒目虚影）；辅助型：聚灵增幅阵（灵力恢复 5 倍、攻击 +30%）；封印型：锁妖封魔阵（暗红锁链束四肢）；传送型：虚空挪移阵（身体化紫光点）；召唤型：万剑归宗阵；组合型：三才绝杀阵（三人占三角，缺一角即失衡）；终极型：周天星斗大阵（场内时间流速减缓、法术威力 ×10）。

**通用结构四件**：阵眼（法器/灵石/修士本身）→ 符文环（1~3 层同心圆）→ 灵力脉络（从阵眼向外辐射的光线网络）→ 范围直径 + 属性颜色（雷紫蓝/火赤橙/冰幽蓝/土褐金/风翠绿/暗紫黑）。**运转三阶段**：激活 0~2s（阵眼亮→符文从中心向外依次点亮→脉络亮起→法阵完整浮现）→ 运转 2~6s（旋转/符文流动/能量汇聚→峰值→释放）→ 消散或破碎（逐渐暗淡；被破则符文碎裂 + 能量反噬爆炸）。

### 三、冲击帧分级

**一句话**：打击的"分量"要靠画面的冲击表现分级，让观众用眼睛"听懂"这一下有多重。

| 级别 | 触发 | 表现 | 白闪 |
|---|---|---|---|
| **一级** | 普攻、普通命中、格挡 | 单帧硬直 / 局部火花 / 轻震屏 | 无 |
| **二级** | 技能命中、落地、多杀、破防 | 明显震屏 + 冲击波环 + 介质飞散（碎光/碎屑/烟尘） | 无 |
| **三级** | 大招爆发、终结技、全屏清场 | 强震屏 + 大面积冲击波 + 光爆 | **3 帧连续白闪** |

三条规则：

1. **分级 = 叙事权重**：一级是节拍里的"点"，二级是"顿"，三级是"轰"。**同一场戏三级只给 1 次**（大招/终结技那一下），滥用即失效；
2. **白闪只属于三级**：一/二级不要白闪，白闪是过曝式冲击，用多了廉价；
3. **特写 + 冲击帧绑定**：关键瞬间（武器形态变化、终结技刺入）给**一帧近景特写 + 一级冲击帧**，把注意力钉在那个细节上。

写法必须是自然句，禁工程标记：✅「刀锋切入甲胄的瞬间，画面一震，碎光沿冲击环向外炸开」；❌「★三级冲击帧 + 3 帧白闪」。

**黑白闪写法硬条**：必须写成自然画面句且带**手绘墨线属性**——纯黑底上的白色纹路粗细不均、有断笔、边缘毛糙、走势歪扭，是手绘笔触不是 3D 射线；严禁术语标签（「★插入黑白闪 #1」「<黑白闪 2帧>」）。

### 四、负面词库（按镜取用，不整张堆）

| 类 | 词条 |

| **节奏类（最致命）** | 开场前奏，环境空镜，建立镜，缓慢起手，蓄力铺垫，对峙观望，原地对峙，站桩打怪，慢动作，升格，顿帧，冻结帧，卡顿，静止机位，匀速平推，0 帧无动态，人物移出画面 |

### 五、R2 的整场骨架（激烈度护栏）

这一层管的是"整场戏到底打没打起来"，与逐镜写法是两个层级。

**六条硬护栏**：

1. **每段必含位移 + 接触**：每个时间区间内攻守双方都必须发生身体位移（冲刺/滑退/翻滚/腾空/被击飞），且至少一次实体接触（兵器交击/拳脚着肉/抓握/撞击）。⛔ 严禁某区间只有"站着 + 发光"；
2. **相邻两段不许同构图**：相邻区间的机位或双方相对位置必须变化，严禁连续两段都是"两人隔距离对视"；
3. **贴身对招占比下限**：15 秒片真正贴身缠斗（身体距 < 1 个身位、有接触）不得少于 5 秒，30 秒片不少于 10 秒；"隔空对波"不计入；
4. **禁止摆拍动词**：「兵器抵住对手面部」→ 改为「兵器捅入对手肋下，对手横飞撞塌半面墙」；
5. **抽掉特效自检**：抽掉所有特效，剩下的纯动作应能连成一段打得起来的武打；只剩俩人站着 = 不达标；
6. **隔空对波的定位**：= 双方站立不动各放能量光束在空中相撞（Beam Struggle）。仅允许用在两处：高潮大招释放瞬间 1~2 秒（作收束点）、短暂反制 ≤0.5 秒（且紧接着必须贴身）。严禁用它填充前中段本该贴身对招的时间。

**【快】拍占比 ≥ 片长 40%**（防"打斗不激烈"的下限，不是目标值；快打碾压型天然 70%+）。

**减速器配额（上限，与下限成对）**：

| 片长 | 黑白闪 | 定格帧 | 慢镜 |
|---|---|---|---|
| 15 秒片 | ≤1 | ≤1 | ≤1 |
| 30 秒片 | ≤2 | ≤2 | ≤2 |
| 短于 8 秒 | 允许 1（招牌不省） | 建议全砍 | 建议全砍 |

**每镜负载上限**：3 秒镜 ≤2 个独立动作单元（IAU = 一次可命中的打击或位移，同一次接触的多写只算 1 个）；4~5 秒 ≤3 个；≥6 秒每多 3 秒放宽 1 个。**一镜只允许一个主任务**，动作类型 ≥3 类即判"一镜多任务"。

**镜内速度四拍（逐镜，顺序不可颠倒）**：① 起（慢，蓄力/重心下沉，占 15%~30%）→ ② 爆（快，蹬地暴起/疾掠，极短）→ ③ 顿（停，命中瞬间定住 2~3 帧）→ ④ 收（慢，卸力/滑步/落地缓冲，占 20%~35%）。**顿拍是全片最关键的一拍**：命中瞬间定不住，观众就没看见"击中"，再多动作也只读作"在乱动"。

**节奏零件库（打戏骨架六件，勿与文戏"情绪节拍"混用）**：蓄（对峙蓄势，0.5 秒内兵刃必须已破空逼近）｜快（贴身交锋，★必选、可重复取用）｜停（战局反转：变招破防/主角挂彩/底牌掀开）｜慢（情感升华，属减速器）｜静（万籁俱寂 + 黑白闪）｜爆（绝杀降临 + 收束协议，★必选）。**三条不可动的骨架**：起手必须有形（0.5~1.5 秒内兵刃破空逼近或双人同框物理接触）｜中段必须有来有回（至少 1 段【快】且双向受力）｜结尾必须有落点（【爆】+ 收束协议，禁平缓收尾帧）。

**参考组合（可拆可改，非必答题）**：A 经典反杀型 `蓄→快→停→快→慢→静→爆`｜B 快打碾压型 `快→快→停→爆`｜C 双强对攻型 `快→停→快→停→爆`｜D 蓄势一击型 `蓄→静→爆`（适合 5~8 秒超短片）｜E 群战乱斗型 `快→快→快→停→爆`。

**五维交替检验**：动作类型（八类：拳脚/兵器/投技/摔擒拿/突刺/反弹/暗器/大招）｜空间调度（远景对峙/中景缠斗/近景贴脸/高空俯冲/低空翻滚/垂直升降）｜景别机位（六档 × 六种）｜速度节奏｜特效密度——任一维连续 5 镜相同即违规。临近大招前 2~4 镜必须有"蓄势低谷"（写战局重整：后撤对视、卸力甩血、拔刀换位，不写弃战）。

**群战与远程的豁免**：远程/枪战/暗杀/追车/大场面/群战乱斗/术法对轰不适用"位移 + 接触""贴身下限""对波定位"三条；但**保底不放行**：不得整场零位移零接触、不得整场无收束。

## R3 玄幻 —— 法术语言系统、剑阵、法相、对军清场、一镜到底群战规程

R3 的最大风险不是"不够炸"，是**用武侠的语言写玄幻**——把法相当成一个巨人去打肉搏，把剑阵当成一堆剑排队飞。R3 有一套自己的语言系统。

### 一、法术语言系统

#### 1. 法术输出五件套（缺一即废镜重写）

1. **特效参数表**——形态／尺寸／颜色／粒子；
2. **视觉比例尺**——人形参照，人物渺小如蚁；
3. **EWS 镜头**——≥1 秒大远景展示法术全貌与人形渺小的对比；
4. **声音五层**——环境／动作／特效／音乐／静默爆发；
5. **冲击帧**——法术对冲用终结级，命中用重击级。

#### 2. 三段式时序（禁止只写"释放法术"）

- **蓄力段**：结印／吟唱／举武器 + 灵力聚集 + 身体变化 + 环境反馈；
- **释放段**：发力动作 + 法术发射／爆发／展开 + 沿轨迹运动；
- **效果段**：命中／展开效果 + 目标反应 + 环境破坏 + **施法者硬直虚弱**。

配套**参数表 11 字段**：法术名／属性／等级／能量来源／蓄力时间／释放时间／冷却硬直／视觉形态（颜色+形状+材质+尺寸）／规格尺寸（直径/高度/覆盖半径/电弧跨度）／物理交互／粒子效果。

#### 3. 等级 → 尺寸 / 消耗 / 破坏总表

| 等级 | 典型尺寸 | 灵力消耗 | 冷却 | 释放后代价 | 环境破坏 |
|---|---|---|---|---|---|
| 小法术 | 剑气 3~10 米／火球直径 5 米／冰刺高 2 米 | 5%（可连发 10~15 次） | — | 无 | 地面小坑直径 1 米 |
| 标准级 | 约 60 米 | 15% | 1~2 秒 | 无 | 龟裂半径 10 米 |
| 绝技级 | 约 100 米 | 35% | 3~5 秒 | 硬直 1 秒破绽期 | 沟壑长 30~50 米／坑洞直径 10 米／烟尘柱 20~50 米 |
| 终极级 | 剑气 200~500 米／剑阵 500 米／环形 300 米 | 70%+ | 10 秒+ | 虚弱 2~3 秒 | 坑洞直径 50 米深 10 米／烟尘柱 200~300 米／山脉断裂 |

（米数仅供脑内定档，输出一律转画面语言）

**等级推断口径（禁"强大的法术"这种写法）**：小法术 = 轻轻一挥/指尖攻击；标准级 = 一招/普通攻击；绝技级 = 全力一击/大招；终极级 = 爆发全部力量/万剑归宗/焚天火莲。

**禁连续放大招**：❌「A 连续放五个焚天火莲，每个直径百米，精准命中 B，B 每次刚好躲开，A 不累」——能量消耗不合理、范围与精度矛盾、无蓄力冷却，三重病。

#### 4. 大场面比例尺铁律

- **视觉比例尺强制**：每次写大场面必须在环境描述里插入至少一处人形参照，写明角色的相对位置与视觉占比。✅「修士站在雷柱底部，身形仅如芝麻大小，紫蓝色天柱雷光直径超过百米，电弧向四周延伸数百米」；❌「雷柱直径超过百米，威力巨大」；❌「火莲升腾，遮天蔽日，毁天灭地」（纯抽象形容词）。
- **EWS 强制**：10 秒时序内至少 1 秒 EWS；人物占画 ≤5%；必须同时含人形参照与特效全貌；运镜用 PULL／CRANE-U／AERIAL；时长 ≥1 秒。
- **EWS 去重**：同场最多 2 次；上一段用 AERIAL，本段必须换 CRANE-U 或 PULL；≥1 秒可拆成 0.5+0.5 但景别不变。
- **范围与精度矛盾**：AOE 直径 >30 米无法精准命中单体，目标必须闪避或格挡。
- **破坏层级**：小法术→地面痕迹；标准级→龟裂；绝技级→沟壑/坑洞/烟尘柱；终极级→山脉断裂/地面焦黑百米/烟尘柱 200 米。

#### 5. 三类巨物的比例尺区分（最易混）

| 类型 | 机位语言 | 人物占比 | 核心逻辑 |
|---|---|---|---|
| **普通爆炸/山崩/大范围法术** | EWS 大远景 | ≤5% | 体现天地宏大 |
| **召唤巨兽/巨龙（外部实体）** | 正面低仰角，人前兽后 | 3%~5% | 体现巨兽压迫；EWS 只作补充 |
| **法天象地/自身巨化** | 低仰角 + EWS 结合 | 法相占 60%~80% | 法相是角色自身的放大版 |

**召唤巨兽的四条硬规**：① 主表现镜禁直接切 EWS（会把人和巨兽一起拉远，削弱压迫感）；② 人物在画面前景下方中央、巨兽在正后方，头颅巨爪悬于人物头顶；③ 写明绝对高度，人物占比 3%~5%，巨兽占画面上方 70%~80%；④ 多镜高度/颜色/形态严格一致，禁中途变形。

**巨兽质感铁律（禁贴图巨兽）**：鳞片层叠有暗光与金属反光；鬃毛毛发**反重力飘动**（灵力场中向上向四周悬浮，发梢缓慢波浪起伏）；爪牙角有磨损与角质纹理；翅膀有翼膜纹理、扇动时弹性形变与翼尖惯性延迟；属性粒子从鳞片缝隙/口鼻溢出、密度随动作变化；体积感（踏步地面龟裂、尾巴扫过空气压缩音爆、转身时毛发 0.3 秒惯性延迟）；主光一侧打来有明暗面，**禁自发光抹平阴影**；胸腔有呼吸起伏、鼻孔喷吐气息。

**法天象地三级尺寸**：标准级·初阶 = 百丈（山脉到膝盖、建筑到脚踝、灵力 35%、持续 10 秒）；绝技级·中阶 = 千丈（山脉到腰部、云层在胸口、50%、15 秒、虚弱 3 秒）；终极级·圆满 = 万丈（头顶天穹脚踏大地、山脉如土丘、城池如积木、80%+、20 秒、虚脱 5 秒）。**法相必须是角色自身形态的放大版**——服装颜色、五官、武器、属性全继承；原比例身体可在胸口/眉心/丹田处作为"法相核心"发光，体现"这是他自己变大"。

#### 6. 8 类剑气气质倾向层

黑白水墨（道家剑意、书画入道）｜黑红紫电弧（魔修、雷魔双修）｜青蓝冰晶（冰系剑修）｜赤金火焰（火系/阳属性）｜银白圣光（正道/佛门剑意）｜墨绿毒瘴（毒修/蛊剑）｜纯金帝王（皇族/龙属性）｜血色杀伐（杀道/血魔）。

铁律：每个角色的剑气类型**全剧锁定**，不可中途变色变形；必须在核心设定里写清"是什么 + 不是什么"；尺寸走四档（常规起手／重击／终结／灭世），输出只写画面语言；**每次挥击同时写宽度 + 长度两个维度**；多角色对战时颜色必须有明显区分；剧本未说明时按角色属性/武器/服装推断。

#### 7. 锚定附着式特效（真实感核心）

核心理念：所有属性特效必须**锚定在服饰、武器、身体表面**，沿纹理自然窜动——禁止凭空悬浮的游离粒子和脱离载体的突兀光团。

| 特效 | 锚定位置 | 运动方式 | 爆发时机 |
|---|---|---|---|
| 电弧 | 服饰纹理/金属纹饰/发丝/剑脊/靴面 | 沿纹理自然窜动游走 | 挥剑/出拳瞬间从手臂肩颈剑身同步爆发 |
| 烈焰 | 长袍衣摆/肩甲/袖口/腰封/发丝/武器 | 沿表面翻涌窜动 | 攻击瞬间沿武器延伸到特效根部 |
| 寒气 | 服饰边缘/武器刃口/指尖/发丝 | 沿表面凝结蔓延 | 蓄力时从指尖/刃口向外扩散 |
| 能量流 | 全身服饰/武器/周身一米内 | 贴身环绕流动 | 攻击时被风压吹直呈放射状 |

必须写明锚定部位 + 爆发时的延伸路径；**人物仅衣摆/发丝/披帛受气流吹拂，主体面部与躯干清晰不糊**。

**冷暖对撞**：一方冷色（冰蓝/幽紫）+ 一方暖色（赤红/橙金），碰撞点形成强烈冷暖对撞，碰撞处产生汽化白雾/湮灭爆闪/色彩交织。

#### 8. 特效介质的四条铁律（38 / 39 / 44）

- **力量不发光，发光必廉价**：打斗默认禁一切"能量可视化"——光柱、能量柱、能量波、光刃、发光武器、气场光环、符文发光、粒子光尘、七彩流光。力量感由物理介质承载：尘土/沙尘暴、碎石飞溅/地裂/凹坑、木屑纸片、水花水雾、雪雾碎冰、火星（瞬间即灭）、布料发丝、断草落叶、烟尘余烬、气浪的实体涟漪。转译：「剑气撕裂空气」→「刀锋过处尘土被犁开一线、碎石向两侧崩飞」；「灵力凝聚」→「周身气流卷聚尘沙成螺旋」。**光柱/能量柱是绝对禁令，无例外通道**（即使点名要法术，也写成两团完全成型的粒子能量体互相撕咬翻涌、接触面层层剥落，不写两根柱子对顶）。
- **武器挥动必拖厚重拖尾（唯一常设白名单）**：燃烧态光带，厚重如实体绸缎、有垂坠有翻卷；边缘翻滚高密度粒子流持续剥落；消散缓慢、残留残像；多段挥击的拖尾可在空中交织成半透明残像之网。颜色绑定角色属性，全剧一致。**拖尾管挥动轨迹，武器本体仍不发光**。
- **0.5 秒超高速**：起手后 0.5 秒内即达超高速交战——首 0.5 秒必须完成至少一次完整攻防转换或一次长距离高速位移，零铺垫、零加速、零蓄势；此后全场速度基准不低于此档。
- **周身属性粒子 = 穿在身上的属性**：每个角色发丝/衣袂/皮肤/武器缠带持续散发属性粒子，颜色绑定主色、材质三粒层（核心亮粒 + 中层雾化 + 外层碎屑）、有流向（静止缓速上浮、加速向后倒掠成粒子披风）、有密度（随烈度增减、大招蓄力八方螺旋汇聚）。**替代一切光环光晕**。

口诀：**柱子全砍掉，粒子穿全身；0.5 秒上强度，一动一糊皆是力。**

#### 3. 剑阵五条通用铁律

- **结构**：写清层数、由外至内依次展开、**相邻两层反向旋转**、每层符文材质不同、层间半透明如透镜叠合逐层折射渐亮、中心符文瀑布或奇点；每层异色（典型：金内/紫中/红外）。**禁规则圆盘、同心圆、机械漩涡、小型传送门**。
- **周期成形**：符文先亮 → 环状阵纹次亮 → 能量纹理逐道流动点亮 → 整体呼吸脉动一次 → 逐层反向旋转展开；成形后仍持续旋转/脉动/流光。
- **发射组织（剑阵）**：整片阵天幕按区域同时亮起群体阵节点，每个节点裂放出数百单位组成的三维鱼群支脉，分区/分层/分批，织成覆盖天地的剑幕；**禁单剑雨、禁侧边单点爆发**；机位在阵外部拍宽度厚度纵深，虫视仰拍用前景兵器剪影当尺度参照。
- **体量**：法阵铺满整片天穹、覆盖全战场、边缘冲出画框，主角极小居中悬浮；**禁贴脚小法阵**。
- **威压反馈**：阵成时地面兵器微颤、场域低鸣、主角每步踩出环形涟漪、白色下压气浪把衣袍发丝压向一侧。

#### 4. 万剑归宗（单独说明，最易写崩）

不是"银色洪流"，不是"剑阵漩涡"，而是**五路立体千剑群流**：每路约千柄、总计五千柄主攻飞剑，呈三维鱼群结构。

- **飞剑规格**：全部正常尺寸冷银窄刃飞剑，剑尖朝运动方向、剑柄在后，每把仅附带少许细密赤红雷痕，红雷**不可覆盖剑身**；禁巨剑/粗剑/单剑领飞；
- **鱼群结构（每路必须写全）**：前部宽阔蓬松、数百把前后错层的群体锋线；中部持续上下换层、前后穿插、斜向补位；后部不断追入回填；边缘持续起伏分流回补；疏密变化沿群体内部传播，外形始终变化。**禁扁平剑板/剑墙/细线剑束/规则圆盘/同心圆/统一旋转中心/中央黑洞/空心剑管/机械螺旋**；
- **摄影机纪律**：只从剑群外部拍摄完整群体，**禁止进入剑群内部、禁止追踪单剑、禁止单剑抢镜**；
- **人形参照**：修士仅占画面 1% 如蝼蚁，万剑星河横跨数公里——人物渺小但绝对掌控；
- **收尾**：停在万道剑群即将全面袭来的瞬间，不命中、不爆炸（命中留到下一镜）。

**光柱转译总则（先于法相库一切内容执行）**：所有纵向光柱类描述一律转译——纵向光柱 → 改为「自阵心拔地而起的成片粒子能量洪流」「两团完全成型的能量体对撞撕咬」「凝聚成型的巨型能量球」；能量可视化载体 → 周身属性粒子 + 武器能量拖尾 + 物理介质反馈（尘雾/碎石/气浪/布料）；**保留原有的形态意图、剧情功能与节奏位置不变**。

**法相场全局参数**：8K、电影级光影、全局抗锯齿、高动态 HDR；分层柔光、高亮实心光效、渐变发光描边、空间光影折射；高密度荧光粒子、星屑光点、流光拖尾、粒子迸溅飘散；丝滑流转、节奏递进、空间扭曲震荡、环形冲击波、天地同频；通透能量体、磨砂柔光、鎏金纹理、雾化光晕、立体分层、史诗仙侠质感；神性压迫、天地恢宏、极致炸裂、高级留白。

**体修法相的特殊口径**：法相段**必须去色转纯黑白水墨**（浓墨勾勒轮廓 + 飞白笔触填充，法相双目纯白发光），这是体修大招的标志性视觉语言，禁彩色；终结爆炸走白橙混合光 → 橙红火焰 → 灰黑烟尘三层色彩演进，之后余波段低饱和灰橙。

### 四、对军清场（割草 / 无双碾压）

主角一人面对成片低阶敌潮，七条同时成立：

1. **敌潮先立势且分层**（近地步卒层 / 中空飞骑层 / 高空俯击层），后排持续补兵、割一排涌一排；
2. **攻击是面状不是点状**——满月/扇形/圆环/光网一扫一整排，碎屑按攻击方向成片飞散；
3. **三联快切锁节奏**：挥剑 → 剑气出鞘 → 军阵炸裂闭环，越切越快、火力全程走高；
4. **群体成批死亡且有反馈**（拦腰斩断/震飞掀翻/碳化黑灰/墨化溃散），**禁敌人凭空消失**；
5. **边位移边割**：沿敌阵缝隙 S 形/V 形高速穿梭，炸点连成横向爆炸线；
6. **碾压比例**：14mm 超广角、人物占比 ≤ 画面高度 1/12，以人小潮大反衬碾压；
7. **节奏曲线**：高频连割 → 弹幕铺网 → 终结技核爆级全域清空。

单挑精英、对等决斗**不套本条**。

**战场空间语法（群战/军阵必写）**：`战场层次 → 主行动线 → 群体压力 → 关键接触点 → 战线结果 → 段末状态`。❌ 不要只写"万人混战、战场惨烈"；✅ 必须写清主角在哪里、敌人从哪里来、镜头在哪一侧、战线怎么变。**分层要求**：前景主角动作 / 中景敌我接触 / 远景战线变化。

| 战场动作 | 可写动作 | 运镜 |
|---|---|---|
| 盾墙推进 | 前排盾牌从画面右侧压入，中景长枪从盾缝探出，主角被迫后退 | 低机位广角，保留盾线方向 |
| 长枪阵 | 枪尖形成斜线压向前景，第一支枪擦过主角肩侧 | 长焦压缩枪尖密度，禁枪杆乱向 |
| 骑兵冲锋 | 马蹄从远景烟尘中逼近，前景士兵举盾下蹲 | 地面低角度，写清冲锋方向 |
| 弓箭齐射 | 远景弓手抬弓，箭雨斜落，中景盾牌接住第一波 | 先远景建立，再切盾牌接触点 |
| 伏击 | 两侧高处旗影晃动，箭矢从侧后射入队伍 | 镜头跟主角视线转向伏击方向 |
| 攻城 | 云梯靠上城墙，守军推下滚木，前景士兵散开 | 广角俯拍建立上下空间 |
| 撤退 | 指挥者后退挥手，前排士兵交替掩护 | 手持侧跟，保持撤退方向 |

**群体结构写法**：禁止"密密麻麻糊一团"。先定义分几路、分几层、每路的前部-中部-尾部，整体像深海鱼群/星河/潮水同相位摆动；镜头停在群体外部看整体轮廓与 S 形/放射动线；**个体只在命中瞬间给近景**。

### 五、一镜到底群战规程（R3 史诗战场协议）

适用：单人（或少数人）对满屏敌军/兽潮/军阵的清场式战斗；无切镜、无空镜转场的高动态战斗；含武器形态变化、超高速位移、阵营色彩对立。不适用：双人对招、室内近身、文戏。

#### 1. 阵营色彩锁（Faction Color Lock）

**敌我各锁一套色系，全片不得互串。**

| 阵营 | 锁定色系 | 覆盖范围 |
|---|---|---|
| 主角/我方 | 暖调（赤金／熔岩赤红／暖金） | 主角光效、招式特效、武器辉光、残影拖尾 |
| 敌方 | 冷调（青白／冰蓝） | 敌人本体、敌人武器、弹幕冲击波、崩解粒子 |

四条铁律：① 主角招式恒暖、敌人恒冷，命中处的火花/碎光是"接触点混色"，**不是阵营色互换**；② 敌人武器不得被染成主角色（即使被打中，也只给"被烧灼的裂纹"，不给"变成红色"）；③ 两套色不得互串（主角光效偶发变蓝、敌人偶尔泛金都算违规）；④ 色彩锁写进全局契约（能量主色 + 对撞色那一位），从"风格偏好"升格为全片硬约束。

**为什么**：一镜到底没有剪辑切点帮你分隔双方，颜色是观众区分"敌我""谁在打谁"的唯一稳定线索。色一乱，满屏混战立刻看不懂。

#### 2. Z 型移位三件套（超音速位移）

**高速位移按"斜前 → 锐角折返 → 斜前"的 Z 字折线突进；每个折点必须留三件套。**

| 件 | 内容 | 写法 |
|---|---|---|
| ① 起点残影 | 折点处原位置留下未散的主角残影 | "起点处一道赤金残影未散" |
| ② 轨迹连线 | 从上一折点连向本折点的熔金轨迹 | "一道熔金轨迹自残影连向落点" |
| ③ 终点凝实 | 落点处光聚凝实、主角显形 | "落点处赤金光聚、主角身形骤然凝实" |

**附带**：每个折点炸开**锥形音爆云 + 环形气浪**；残影保留 0.1~0.2 秒后凝实再溶解；三段轨迹在空中**连成可见的 Z 字形光轨**。

**机位**：贴追折点、每个折点**甩镜过冲回正**；Z 字光轨以俯拍角度完整入画；强动态模糊拉满。**Z 型折线 = 3 次锐角变向，段内不切镜**。

#### 3. 敌数单调递增（Monotonic Escalation）

**敌人数量随时间单调递增、绝不回落——直到清场那一下。**

| 阶段 | 密度 |
|---|---|
| 开场 | 数百只铺开（**首帧即满屏，禁空镜/前奏**） |
| 中段 | 上千只；精英单位（持械兽将/精锐兵）开始成排踏出 |
| 终局前 | 密密麻麻挤满画面每一处缝隙，连天光都被遮去大半 |
| 清场 | 大招一扫而空 → 清净 → 尾帧定格（**数量骤降只允许发生在最后一次清场**） |

四条铁律：① 单调递增，任何一帧任何方向都必须看到成百上千的敌人（"打着打着敌人变少了" = 违规）；② 规模成片，每一招的杀伤必须是"成片/成排/上百只"，**禁单个点杀**；③ 优先补员——清掉一部分后从更远处涌来更多，不许清空一片就留白；④ 精英分层且逐幕递增（零星 → 成排 → 整队压上 → 四面围杀）。

**为什么**：单人 vs 群战的爽感来自"永远打不完的压迫感"；数量回落会让观众觉得"快赢了"，张力立刻泄掉。

#### 4. 武器形态单次变形

全片**只允许武器变一次形**，且必须完整演出，绝不凭空换模。五步模板（以「一剑化双刀」为骨架，可迁移）：

```
① 核心反应：剑脊脉线亮至极限、剑体剧烈震颤（能量在上限积压）
② 一分为二：从中脊一裂为二，吞口/护手左右各分一头，器灵/龙影脱出盘旋一周
③ 各向延展：两段各向两端延展成刃，一刃暖色熔岩、一刃暗色沉敛（一明一暗）
④ 配件展开：柄尾流苏/链坠甩出并燃亮
⑤ 成式定姿：双手各接一器、交叉成起手式，一声金属咬合脆响荡开（涟漪/气浪）
```

全程约 0.4 秒（快但不"瞬移换模"）；分化前持原武器要有明确起势（举过顶收束能量），分化后直接接第一招；变形瞬间给一帧近景特写 + 一级冲击帧。**写作禁区**：❌「剑突然变成两把刀」❌「不知何时手上多了一把刀」❌「双刀又合成一把剑」❌用剪辑/切镜掩盖变形过程。

#### 5. 蓄力涡旋与尾帧定格

**蓄力涡旋**：双器交叉高举向天 → 周身所有光效/火焰疯狂向器身汇聚 → 天光被吸引形成巨大涡旋 → 涡旋中心盘踞器灵/龙影 → 身体压低、前足虚点、后足蹬满。**蓄力期间四周敌人仍在成阵列压来**（数量已满屏）——蓄力不能把背景抽空；机位极速仰拍，满屏能量涡旋 + 四周压来的敌潮剪影；**蓄力中绝不停顿**（零顿帧）。

**尾帧定格**：末镜起进入收束窗，人物停止大幅动作；末镜末 1 整秒保持姿态与站位、画面定格（整秒硬定格，剪辑时整秒剪除）。定格帧要干净利落：主角姿态完美、碎光飘落、战场空无活物或只剩残局。**双重作用**：① 艺术收束逼格拉满；② **作段缝依据**——直接截取该末帧作下一段的画面依据，一致性 100%。定格必须发生在终结动作完成之后（未杀完的定格、收势未完成的定格 = 违规）。

## 构思层先于画面层 —— 方法论

写打戏最容易犯的错是**从画面开始**：先想"我要一个满月剑光、再来一个巨型冲击波"。这样写出来的场面很漂亮，但没人看得懂为什么打、谁占上风、看了有什么感觉。正确顺序是：**先想清"为什么打、打向哪里"，再想"怎么拍才好看"。**

### 一、两层分工

| 层 | 管什么 | 归属 |
|---|---|---|
| **构思层（叙事层）** | 动机 / 强弱错位 / 赌注 / 环境变数 / 五段情绪 / 感官 / 心理 | 先做，决定每一镜"为什么打、打向哪里" |
| **画面层（编排层）** | 特效 / 速度 / 节律 / 机位 / 帧率 / 冲击帧 / 收束 | 后做，决定"怎么拍才好看" |

两层缺一不可：没有构思层，画面层只是特效堆砌；没有画面层，构思层只是大纲。

### 二、底层设定四件套（先定这个，再写动作）

1. **双方动机**：每个人为什么打——复仇/保命/保护他人/被逼应战/被蛊惑/赌上尊严。主角不为"打赢"而打（身后有要守护的人），反派不单纯坏（有执念，打斗带情绪）。**动机必须外显为打斗中的情绪细节**（眼神、犹豫、狠劲的来源）。没有动机的打斗只是招式复读。
2. **强弱错位（禁碾压、禁全程被压）**：主角有优势也有短板（速度快但防御弱、招式大开大合但体力差），对手有明确战斗风格（蛮力型/敏捷刺客/法术内力型/阴险诡诈型）；力量不如对手就靠技巧、环境、临场应变弥补。**禁主角全方位碾压，也禁全程被压着打**。
3. **赌注（紧张感之源）**：输了会发生什么——死亡/亲人遇险/信仰崩塌/任务彻底失败。赌注越高越扣人心弦；打斗中每一步压迫都要指向赌注。
4. **战场环境变数**：禁止永远空旷平地——废墟碎墙、崩塌建筑、狭窄回廊、雨夜湿滑地面、破碎兵器、高处悬崖、火光烟雾、可破坏障碍物。**高手借环境**：踩碎石、撞断梁柱、利用遮挡偷袭；**环境必须被战斗逐步摧毁**。开局必须列出**可交互物体清单 + 刚性几何锚点**（哪根柱子能撞断、哪块地面会塌、哪道门能穿）。

### 三、五段式打斗节奏（起 → 承 → 危 → 破 → 收）

一张一弛，有快打也有停顿喘息。**禁从头打到尾**。

- **【起·交锋开启】**：简短铺垫气氛后第一波碰撞即来（衔接"0.5 秒超高速"）；双方试探摸底、招式往来势均力敌，**不一上来开大**——脚步腾挪互相试路数。
- **【承·对手占上风·危机降临】**：局势反转，主角落了下风——对手亮杀招，主角被压制、受伤、兵器受损。写痛感与体力透支，压迫感拉满。关键：让观众真切感到"主角快要输了"。
- **【危·低谷喘息·心理博弈】**：不许一直打——双方拉开距离，大口喘气、伤口流血、言语交锋；回忆/执念/守护的念想在此闪过，主角在此找到破局思路。**心理对抗与动作对抗同等重要**。
- **【破·高潮破局·决战一击】**：主角**不是突然开挂战力暴涨**，而是利用对手破绽（自大/旧伤/招式硬直）、环境、自己的特长、牺牲部分代价（弃武器/硬扛伤害换机会）反击，打出决定性连招。**破局手段必须是前面铺垫过的招式/伏笔/环境要素在此回收**，禁毫无铺垫的实力爆发。
- **【收·战斗落幕·代价显现】**：分出胜负但不戛然而止——赢也不是完美胜利：满身伤痕、兵器损毁、体力耗尽；处理结局（击杀/击退/劝服），收尾带出人物情绪与胜利背后的沉重。不打完就翻篇。

### 四、感官（每段至少调用三类）

- **听觉**：金铁交鸣／骨骼闷响／碎石崩裂／喘息嘶吼／衣服撕裂／爆炸轰鸣；
- **视觉**：刀光残影／飞溅血迹（ZeroBlood 时改粒子碎片）／烟尘飞扬／火光月光的光影变化／肢体动作与伤口；
- **触觉体感**：冲击震得手臂发麻／伤口灼痛／汗水模糊视线／地面湿滑／劲风刮脸；
- **动作细节**：侧身翻滚躲闪／格挡手臂震颤／踉跄稳住身形／肌肉紧绷。

**快慢结合**：高速缠斗写短句切割画面，对峙蓄力用长句渲染氛围。

### 五、镜头分镜思维（画面感分层）

远景看整体战场与破坏；中景看全身招式腾挪闪避与兵器交锋；近景看面部神态（眼神/咬牙/伤口流血）；特写看兵器裂纹/握紧的拳头/滴落的鲜血/受伤的手；动态残影给高速攻击（本体只留残影 + 尘土炸开）。**景别机位具体执行仍按交替规则走。**

### 六、六大避坑（生成后反向自检，命中即改）

1. **禁招式无限堆砌**：全程打来打去无情绪无局势变化；
2. **禁主角强行开挂**：前面被吊打、毫无理由突然爆发秒杀——破局必须有铺垫；
3. **禁只写动作不写心理**：人物无恐惧愤怒决绝，打斗像木偶表演；
4. **禁环境完全透明**：空地互殴不用周边事物；
5. **禁胜利零代价**：打完毫发无伤，紧张感归零；
6. **禁节奏从头打到尾**：无起承危破收的平推。

### 七、全局节奏规划（逐镜生成前必做，禁止一上来就拆镜头）

**节奏曲线五型**：

| 类型 | 曲线 | 适合 | 快切 / 长镜 | 备注 |
|---|---|---|---|---|
| 渐进爆发型 | 慢→快→爆→收 | 单挑、突破 | 40% / 30% | 静默点 = 爆发前 0.5s |
| 持续高压型 | 快→更快→最快→余波 | 围杀、逃亡 | 60% / 15% | 1~2 次喘息 |
| 张弛交替型 | 快-慢循环 | 多回合攻防 | 50% / 35% | — |
| 文戏主导型 | 慢→微澜→慢 | 对话对峙 | 10% / 70% | — |
| 混合叙事型 | 文→打→文→打 | 复合场 | 35% / 45% | — |

**爆发点定位**：全场 1~3 个，在时间轴上标注具体秒数；爆发点前 2~5 秒蓄力铺垫、后 2~3 秒余波展示。禁全程无爆发点，也禁每 10 秒一个（超过 3 个等于没有）。

**快切与长镜配额**：快切 2~3 秒/镜用于高速交锋，单段连续快切 ≤5 镜后必须插 1 镜长镜或特写呼吸；长镜 8~10 秒/镜用于蓄力/情绪/大招，单场 ≥2 镜；特写每 3~4 镜插 1 镜，禁连续 2 镜同部位特写；空镜每场 ≥1 镜。

**静默设计**：全场 1~2 次完全静默（0.3~1 秒，环境音全停），放在爆发前 0.5 秒或情绪顶点；禁静默超 1 秒（刻意戏剧停顿除外）。

**技能升级阶梯（大招必做）**：一浪高过一浪，禁开场即最大——按镜头顺序列尺度等级（小→中→大→终结），最终大招突破场景尺度极限。范例：百米坑 → 连爆递进 → 坍缩球 → 光矛雨 → 熔岩海啸 → 升空恒星 → 宇宙级核爆 → 收束。

**三幕式时长结构（30 秒以上）**：第一幕·建立 15%~20%（打戏第一幕 ≠ EWS 铺垫，是**开局即战中**用 1~2 个交击镜头建立对抗关系）→ 第二幕·发展 55%~65%（冲突升级、节奏渐快、景别跳级）→ 第三幕·高潮收束 15%~25%（CU/ECU 与 EWS 交替，收束 MS/WS 拉远 + 空境/背影）。

**六套剪辑节奏公式**：呼吸式（快切 3~5 镜 → 1 镜长镜，连招后收势）｜心跳式（静态 → 微推 → 正反打加速，对峙悬念）｜海浪式（景别渐紧 → 爆发 → 余波长镜）｜子弹时间（跟拍 → 升格 48~240fps → 爆速 + 冲击帧）｜脉冲式（2~4 短镜快切 → 1 镜重击定格）｜静默锤击（0.3~1s 全静默 → 爆发全频段峰值）。

### 八、八步写作脑（画面层的总执行链，脑内走，不输出）

| 步 | 内容 |
|---|---|
| **第 0 步 定全局契约**（全场一次） | 风格技术栈；一个能量主色 + 一个对撞色 + 暗部高光双色偏；每种特效的三层材质（从 13 种复合元素调用，不自编）；战场几何与可破坏锚点；人效运动关系；节奏曲线 |
| **第 1 步 派镜头任务** | 一镜一主任务：证规模/证力量/证速度/证招式/证招式轨迹/证情绪（≤1 秒特写） |
| **第 2 步 据任务定机位** | 观众站哪、多大、什么角度、看哪条轴。宏观用 14~24mm 超广 + 超远景；力量用贴地虫视 + 命中特写；速度用贴肩追尾；群体用外部机位看整体轮廓。前景放已知大小物做比例尺 + 遮挡纵深 |
| **第 3 步 写可发力的身体** | 蹬地→转胯→腰→肩→手的完整链；脚有接触点和碎裂反馈；零滑步零漂浮；**动作是特效的因** |
| **第 4 步 特效从身体/武器长出来** | 调第 0 步的三层材质 → 选几何形态（柱/环/螺旋/放射/球/网/龙形/鱼群/裂谷/界门）→ 大特效强制尺度四件套 → 写清生命周期（怎么聚、沿什么轴线飞、命中、怎么散） |
| **第 5 步 写力的三张回执** | 命中按轻/重/大招套冲击帧；受力体形变 + 位移；三层粒子 + 地空尘连锁破坏留痕；镜头按攻击方向受力 |
| **第 6 步 用有质量的运镜拍出因果** | 运镜由事件驱动（能量上冲镜头抬升、火浪逼来镜头后撤、命中镜头猛沉回弹）；高速段才局部滞后、人快于机、甩出画框再补抓；跨级切景别制造尺度跳跃 |
| **第 7 步 排镜头间因果与节奏** | 上一镜末 = 下一镜首；快—顿—慢—极速；蓄力越久爆发越狠；会用延迟揭示（收鞘咔哒 → 裂纹蔓延 → 延迟爆山）；阶梯拉远做史诗 |
| **第 8 步 反向锁死** | 段末负面清单把本镜最易崩的点逐一禁掉 |

### 九、尺度四件套（每条大特效必过）

写大特效时，**画框分数 + 宏观量级 + 参照物 + 人物占比**四项必须同时落地，缺一即废句重写。米数只在脑内定档，**输出一律画面语言**；**用户给的数值一字不改**。

### 十、收束四协议（结尾不许糊）

行业通病：大招炸出百米天坑后，收尾 1~2 秒在前景平地凭空"闪现"一个跪地的对手（时空穿帮）；或最后一秒两人脸贴脸架刀对推。收尾 2~3 秒必须从四协议明确选一：

- **协议 A·遗物定场型**：胜负已分、败者坠入深坑，重意境与史诗残局。前台严禁出现败者肉身；坑沿碎石裂缝中仅斜插一柄断裂冒烟的残兵；镜头只拍胜者背影与残兵向远空拉远。
- **协议 B·物理抛飞隔离型**：败者未死、需交代苟延残喘。禁同一平面同框；写明极远力学轨迹"呈抛物线向侧方横向轰飞两百米，砸嵌在远景千米外的断裂岩壁"；前台胜者 vs 远景败者拉开数十倍纵深。
- **协议 C·写意光粒湮灭型**：既分胜负也决生死。贯穿爆心的同一瞬，败者身形被极烈光芒撕裂、瓦解成漫天属性光粒子随狂风向天穹倒卷消散；前场仅留胜者持剑立于大坑前目送光雨飞升。
- **协议 D·战意永动纯打斗硬收尾**（专治贴脸堆叠，二选一）：① 反向错车·背向飞出画框——两人极速交错斩击的瞬间擦身而过，火星在半空拉成一道横向裂缝，错车后以超音速背向反弹，一白一红朝画面对角冲出画框，画面在两道流光背道而驰中黑场硬切；② 单人特写·刀光冲镜硬切——极端特写、眼神杀意暴涨、一剑怒劈，剑芒瞬间填满画框，在劈中镜头的最高峰直接硬切。

**致命陷阱**：写"绝无两人贴脸堆叠对推"会因粉色大象效应被模型抓成正向特征画出；"迎面暴冲对撞""对视"等词天然带聚拢倾向。**要用正向的发散位移描述，而不是否认句**。

**口诀**：A 留物不留人，B 抛出画框外，C 当场化光散，D 错车硬切开。

### 十一、主角反杀的主客反超（R2/R3 通用）

痛点：反派放了极为震撼的大场面（百米冰晶巨莲、万丈血海），主角绝杀却只有 0.5 秒或只写"一轮满月剑波"，模型画出单薄光条随手弹走——视觉主次倒挂。

1. **时序窗口刚性保障**：对手大范围招式在 0~10 秒完成展开；10~15 秒整整 5 秒全额留给主角反杀三步走（破局蓄势 → 巨型立体大招 → 碾压命中与环境回执）。30 秒档按比例前移。
2. **前摇与极距蓄压（0.5~1.5 秒）**：破除束缚（特写全身剑气真元暴震、束缚物轰然炸裂成漫天碎晶粉末）→ 能量向心压缩（千万道雷弧从兵器根部向尖端疯狂收束，凝成比烈日还耀眼的炽白光核）→ 气场反向掀卷（发力风压把长发与战袍反向掀向天空）。
3. **宏观物理厚度（禁 2D 单薄光条）**：❌「紫霄神剑爆开一轮满月红紫剑波」→ ✅「自长剑斩出一道宽达三十米、纵深数百米、厚如城墙的巨型立体红紫开天剑罡（主体白炽雷电 + 边缘暗红飞白 + 两道撕裂云层的白色音爆环）」。
4. **视觉反超**：用"破坏对手的宏伟造物"证明主角更强——剑罡横切而过，沿途数十根百丈冰刺被齐根腰斩崩碎。**借对手的壮观特效当背景板**。
5. **命中必须横推碾压**：巨刃正面横撞，如开天巨斧平推，对手连同周围残岩一同被向后横推数百米、砸穿远景绝壁激起冲天尘幕。**不要"轻飘飘弹飞"**。

### 十二、双人放大招（串行施法）

AI 生成双人大招的通病：同画面同时施法互相吞并、单方吞招、人物出画截断。硬规则：

1. **禁同画面同时施法**：先给角色 A 的大招在独立画面完成全流程，再切镜给 B 完成全流程；禁"两人同步起手蓄力"；
2. **每招独立成镜、完整呈现**：施法→蓄力→成型三阶段全给足；串行 ≠ 干等——非施法方以战场另一端远景备战状态存在（衣发激扬、能量盘旋、磨刀按剑），禁站桩等待；
3. **双方成型后再对碰**：两套大招 100% 完全成型（色彩分明、互不覆盖）之后，才切全景/超远景进入对冲；碰撞写成两团成型能量体互相撕咬翻涌、接触面层层剥落；禁抬手即撞、蓄力阶段互相抵消；
4. **对碰段稳全景、短特写**：主镜全景/广角，特写只做 0.8 秒以内极速闪切。

**60 秒双大招节奏**：0~6s 对战中段切入 + 双方拉开距离 → 6~20s A 的大招独立成镜 → 20~34s B 的大招独立成镜（运镜与 A 差异化）→ 34~48s 对冲爆发 → 48~60s 余波收招。

**口诀**：大招不许同框施，一招一镜放到底；两招都成型，中场再对碰；串行不吞招，远景不站桩。

### 十三、几个必须记住的物理总规

- **每击必爆（三分支当拍必爆）**：命中 = 受力方反应 + 地面炸裂；**被挡** = 冲击环外推 + 残墙尘浪；**击空** = 能量打进环境。**攻击不落空**。
- **爆炸八拍**（可压缩不可乱序）：① 接触前空气向内压缩塌陷 ② 第一爆点白芯爆亮 ③ 球形冲击波 + 环形气浪 + 体积爆云分层外扩 ④ 真空回吸 ⑤ 再向外吹飞 ⑥ 环境破坏 ⑦ 爆炸逆光勾勒人物轮廓 ⑧ 余波留持久痕迹（焦黑/余火/尘墙），痕迹沿轨迹成线、保留到后续镜头、不复原。
- **层级物理破坏（L1→L4 有时间差）**：L1 裂线 T+0s（细黑线贯穿整体）→ L2 冒光 T+0.2s（裂缝中漏出属性光）→ L3 皮炸 T+0.7s（表层十米岩皮炸成碎石雨、烟尘柱升起）→ L4 芯爆 T+1.4s（最深处核心爆成属性蘑菇云、半个天空被染色）。**大场面不是"一下全碎"，是分层级、有时间差、有重量感的连锁。**
- **三层粒子并行**：底层厚重卷尘（体积渲染散光）｜中层崩裂岩片/熔融液滴（带拖尾运动模糊，遵循空气动力学）｜顶层高温电弧/热浪扰动（非线性折射畸变）。
- **大气透视**：近景高对比、属性色饱和、明暗交界锐利；中景灰蒙沙尘过渡、饱和度降；远景冷青灰衰减。**禁全画面统一饱和度。**
- **五类标准位移**（禁无接触飞行/漂浮）：蹬柱接力（每踏崩出碎石）｜踏壁折返（脚下蹬踏凹痕）｜屋顶跑酷（瓦砾崩落）｜空域飞天（破空音爆环 + 气流拖尾，唯一允许无脚接触、但有空气压缩）｜地面音速折返（S/V 形，犁沟 + 尘浪 + 碎石追飞）。位移起点 = 反作用力爆散，终点 = 能量从尾端追上来包裹身体（惯性延迟 0.2~0.5s）。
- **收尾必须动态**：禁双方同框站立摆 pose、禁站定定格。结尾要么镜头暴拉到 EWS、人物缩小到千分之一画幅如微尘、余波填满画面；要么胜者动态背影 + 破坏余波；要么败者飞出画面/撞穿建筑/坠入深渊/写意光粒湮灭。人物越来越小却始终居中。

## 打戏投喂要点 —— 与 Seedance 2.5 / 2.0 的衔接

打戏稿最终要变成一条能直投模型的提示词。这一步最容易在两个地方翻车：**把 2.5 当 2.0 用**（堆一堆 3 秒微操，模型全丢），**把 2.0 当 2.5 用**（要求 30 秒一镜成片，模型崩）。所以投喂前必须先锁定档位。

### 一、双档对照（2.0 vs 2.5）

| 维度 | Seedance 2.0 档位（单镜切片） | Seedance 2.5 档位（30s 一镜成片） |
|---|---|---|
| **单段时长** | 5s / 10s / 15s 单镜头独立生成 | 30s 完整长视频直出，多镜头连续叙事 |
| **时序控制** | 镜头序号（`Shot 1`、`Shot 2`）或细切时码 | **严格整数秒时间戳**（0-7秒、7-15秒、15-23秒、23-30秒） |
| **动作密度** | 每 2~3 秒 1 个核心攻防动词 + 1 个受力反馈 | 遵循「概括动线 + 少数记忆点动作」，**严禁 3 秒内堆 10 个微操** |
| **音频控制** | 需外部挂载音频或后置 BGM | 原生音频自然句（`生成金属碰撞声与风雨声，无bgm`） |
| **多模态参考** | 1~5 个主体图/首尾帧参考 | 最多 50 个参考素材，支持多视图主体图与连续时间戳编辑 |
| **收束模式** | 协议 A/B/C/D 均可适用 | 推荐协议 C（光粒解构）与协议 D（反向错车背向出画硬切） |

**档位选择**：总控已锁定档位时跟随总控；未指定时——**单场打戏（≤15 秒）走 2.0 单镜切片，完整打斗段落（20~30 秒连续叙事）走 2.5 一镜成片**。

### 二、Hit-Stop 顿挫：2.5 专属，2.0 只能靠接触瞬间的画面本身

这是两个档位最重要的一处分野，**写反了等于白写**。

**Seedance 2.5 —— Hit-Stop 可以写、必须分级写。**

在 2.5 一镜成片里，"顿"是**提示词里明确写出的时间事件**，模型会执行。三级锁定，禁所有命中套同一档：

| 等级 | 顿帧时长 | 升格 | 缩放冲击 | 画面表现 |
|---|---|---|---|---|
| 轻击 | 0.1s | 48fps | 微缩放 | 受击部位微形变，机位微微一挫 |
| 重击 | 0.15~0.2s | 120fps | 缩放冲击 | 放射冲击 + 中心负片 + 受力猛沉回弹 |
| 大招 | 0.25s 以上 | 240fps | 缩放 + 定格锁机位 | 全屏负片闪白 + 机位纹丝不动 |

三种可直抄的顿帧写法：

- **常规**："极短顿帧：碎石、衣摆、火星同时凝滞，环境声瞬间抽空，下一帧爆速——"
- **终结**："240fps 超升格 0.3 秒：所有碎片钉死悬停 → 空间玻璃裂纹从命中点蔓延 → 时间恢复 → 全屏白光爆发"
- **大招定格锁机位**："定格瞬间机位纹丝不动，震屏抖动全部停止，0.3 秒窒息静默 → 下一帧爆速恢复，震屏最剧烈"

**配镜内速度四拍**（2.5 推荐写法）：起（慢，蓄力/重心下沉）→ 爆（快，蹬地暴起）→ **顿（停，命中瞬间定住 2~3 帧）** → 收（慢，卸力滑步）。四拍是 2.5 的强项，一镜里能真正演出来。

**Seedance 2.0 —— 不要指望它执行"顿帧/时停/帧数"。**

2.0 是单镜切片，15 秒以内的图生/文生，对"顿住 2~3 帧""240fps 超升格 0.3 秒"这类**时间指令几乎没有执行能力**——写了也不生效，还会占掉注意力预算、挤掉真正该写的动作描述。2.0 的"打击感"必须**全部落在接触瞬间的画面本身**：

1. **写形变不写时间**：不写"定住 0.2 秒"，写"接触的一刻，受击者胸口整个凹陷下去、背部弓成 C 型，衣料被顶起一道皱褶"——把"顿"翻译成**一帧里看得见的东西**；
2. **写画面状态词**：碎石、衣摆、火星**同时凝住**；血滴悬在半空；刀锋停在被劈开的布料边缘——让模型自己把这一帧画得"稳"，而不是让它去控制时长；
3. **用升格描述替代帧率**："极慢地"、"在极慢的升格里"、"放慢到几乎静止"这类**自然语言**，比 fps/帧数可靠得多；能量化时用"极短"、"一瞬间"、"半个呼吸"；
4. **把力写进镜头反应**：机位微微一挫、镜头被冲击波推后、画面一震——**镜头动了，观众就读到了"打到了"**，这是 2.0 环境下最稳定的顿挫替代品；
5. **靠剪辑做顿挫**：2.0 是切片，"顿"可以交给**后期**——命中帧单独抽出来重复 2~3 帧、或加一个 0.1 秒的微缩冲击。提示词里只管把那一帧画到最满。

**一句话记法**：**2.5 写时间，2.0 写那一帧。**

### 三、2.0 档的投喂结构（单镜切片）

- **一条切片 = 一个主任务 + 一个核心攻防动词 + 一个即时受力回执**；每 2~3 秒一个核心动词，禁 3 秒塞 10 个微操；
- 时序用镜头序号或整数秒细切；
- 收束四协议（A/B/C/D）皆可用；
- 15 秒以内不要追求"一镜到底"，切片之间的**末帧接首帧**才是连贯感的保证。

### 四、2.5 档的投喂结构（30 秒一镜成片）

**六条官方硬规（踩一条就废稿）**：

1. **单段时长**：2.5 原生支持单段最高 30 秒（一镜成片与多镜头叙事均可），无需强制拆成 10 秒；但**段内子节点必须按整数秒（2~4 秒）有序排列**；
2. **时间戳**：严禁小数点与冒号时码（`00:03.2`），必须整数秒（`0-3秒` / `3-7秒`）；
3. **严禁大分镜嵌套**：30 秒提示词不得写成 `S01 0-10s / S02 10-20s / S03 20-30s` 这类嵌套场次代码，必须从 0 秒一路连续推进到结尾；
4. **彻底清洗元指令与代码符号**：严禁出现 `<音效：…>`、`★正面重击`、`模式K`、`协议C`、【第一段】等给人类看的标记——模型不理解这些行业术语，反而会被特殊符号与尖括号占满有效注意力；
5. **原生音频与负向控制**：音频直接在结尾写自然句（`生成金属刀剑劈砍碰撞声、肉体受击闷响与狂暴雷鸣风雨声，无背景音乐（无bgm）`）；字幕排除写（`不要字幕，画面无任何文字与水印`）；**在没有独立 Negative 框的环境下，严禁正文大段堆砌负面词**——长篇"禁止站桩、禁止穿模"会诱发粉色大象效应，必须改为正向动作描述；
6. **单文本框（A 轨）执行细则**：只输出一条连续干净的自然画面流——**画质基准句 → 角色·场景·核心设定句 → 整数秒时间流 → 结尾自然句收束**；有独立负面框或需要分镜剪辑稿（B 轨）时，负面清单只出现在末尾独立负面块里。

**口诀**：**整数秒、别嵌套、洗干净、音频负向都写自然句。**

### 五、打戏正文的两种装配轨（A 轨 / B 轨）

| 轨 | 适用 | 结构 |
|---|---|---|
| **A 轨（默认）** | 单文本框模型 | 一条连续干净的自然画面流：画质基准句 → 角色·场景·核心设定句 → 整数秒时间流（每个 2~3 秒节点一条熔好的长句）→ 结尾自然句收束（音频/无字幕）。**严禁元指令、代码符号、大段负面词** |
| **B 轨** | 有独立负面框 / 需要分镜剪辑稿 | 正文 + 末尾独立负面块；负面块只装负面清单 |

段内的每个节点都写成"镜头先动 → 人物在镜头里动 → 镜头再动 → 下一动作命中"交替咬合的一条流动长句，**禁止分块罗列**。

❌ 错误（分块罗列 + 单层光 + 动作环境分家）："【位移】凌云瞬移到兽头顶斜劈。【运镜】贴肩追拍→急摇。青白三层剑光。触轻击级。地面裂。"

✅ 正确（镜头先行交替 + 全内嵌 + 同拍）："镜头先贴凌云肩侧、顺前冲方向低机位猛窜、剑风几乎擦镜，就在前冲这一拍他身形炸成四五道水墨冰晶残影、淡金边勾着残影向后飘散、周身青白雾被风压倒拖成锥形飞白；镜头跟住最实那道残影一个甩镜到兽群头顶、急停钉死，停的这一瞬青锋已斜劈而下，主体水墨飞白像撕开黑幕、边缘青蓝水浪顺刃翻卷、表面冰晶核心与金边一起迸射，能量剑罡、水墨飞白与被卷成流体的尘沙绞成一股，几乎同拍最前排妖兽与脚下龟裂地面一起炸裂、尘浪碎石成扇面同步掀飞，命中那一帧黑白一闪、从劈点向外猛拉扭曲、强光短暂吞没兽群随即恢复爆速，炽白核心 → 青蓝水墨雾化 → 冰晶碎与黑灰顺重力飞溅。剑锋擦着一头妖兽的脊背划过，兽身擦镜。"
